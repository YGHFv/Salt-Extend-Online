# Salt Extend Online 0.8.0

产物：`plugin/build/libs/plugin-io.github.yghfv.saltneri.online-0.8.0-playlist-state.spmod`。

## 页面与合集

- B站和网易云各自保留当前目录、分页、排序、搜索、选中行和滚动位置。离开页面不再清空目录；未提交的播放意图仍取消，已播放的音轨不因导航撤销。
- 元数据只在本次插件生命周期的内存中保留；重新点栏目可刷新。退出、换账号、权限撤销、停用后旧行操作失效，不把旧账号列表交给新账号。
- 合集 / 收藏夹行显示 `名称 (数量)`，详情标题同样显示总数；未知数量不伪造为 0。作者读取 `upper / owner / creator / author`，创建的收藏可回退到已验证账号昵称。不再用「视频合集」占据作者位置。
- 详情标题行右侧依次提供播放、搜索、排序。两个搜索入口都在图标左边直接展开输入框，不新增一行；输入后回车或点击图标提交，空合集关键词恢复全部内容。
- 合集内搜索匹配完整合集的标题和作者，不只过滤当前页；排序支持原始顺序、倒序、标题、作者、时长，显示仍每页 20 项。
- 首次整单播放、合集搜索或排序按需收集全部元数据，最多 500 页 / 10000 项，180 秒总体超时，取消或失败不提交部分队列。普通浏览不抓取全部目录。
- 标题数量沿用上游合集总数，过滤结果的页数按匹配项计算；失效条目仍隐藏。

## 整单播放

- 播放按钮指整个合集，采用所选排序，但不缩减到当前搜索结果或当前页。
- 使用实际 Salt `setPlaybackQueue(List, 0)` 后调用 `play()`，不追加到旧队列，也不调用播放 / 暂停切换。
- 首曲先解析成功，再替换队列；首曲解析失败则保留用户原队列，不伪装成提交成功。
- 队列先持有逻辑曲目，Salt 实际打开下一首时才调用原有平台解析器；音频签名 URL 不提前为整单生成，不写入队列或磁盘。
- 音轨租约缓存最多 8 项，过期 / 淘汰后播放时重新解析，账号和权限变更撤销映射。B站仍默认每个视频的 P1，不把一个多 P 视频展开为全部分 P。
- 动态取回歌曲标题、作者和原比例封面后更新对应队列项；临时封面文件沿用既有封面机制，停用时清理。
- 后续曲目若被删除、收费或平台拒绝，解析会失败，不绕过权限；宿主失败后是否继续下一首由 Salt 控制。

## Bilibili 发现

参考本机与 GitHub 对应的 NeriPlayer `fd7fdb757821fda7a62aee3a2b7cecf3a4b8bfe0`：

- 音乐分区热门视频：`https://app.bilibili.com/x/v2/rank/region?rid=3&type=all&pn=1&ps=100`。不使用已冻结的 Web `ranking/v2?rid=3`。
- 音乐热门榜 / 原创榜：`all_period?list_type=1/2`，按发布时间及 ID 选择最新一期，再读取 `music_list?list_id=...`。
- 榜单先选择官方 MV 身份，缺少 MV 身份时使用关联投稿；无有效视频身份直接隐藏。不预抓音频。
- 与 NeriPlayer 的差异：此处不批量补取全榜 MV 资料，真实视频资料和权限在双击播放时经现有解析器验证；未知 MV 时长不借用关联投稿时长。
- 三种发现请求均匿名只读，不发送已登录账号 Cookie；每页显示 20 项，支持普通单击选中和双击播放。
- 已通过插件真实 HTTPS 客户端进行公开元数据探测：热门视频 100 项 / 5 页，热门榜 20 项 / 1 页，原创榜 17 项 / 1 页（数量随平台更新）。未读取账号或请求音频。

## Windows 媒体名称

- 本机只读系统媒体会话检查返回 `Salt Player for Windows.exe`，不是插件名；宿主 SMTC API 不提供单独的应用名称 setter。
- 新增进程 AppUserModelID 及当前用户 `Software\Classes\AppUserModelId` 的显示名称 / 图标注册，同时覆盖进程现有的隐式 exe 名称身份。
- 显示为 `Salt Player for Windows`，不更改音乐标题、作者，不修改宿主 EXE、Steam 文件或机器级注册表。
- 已有显示名称不覆盖；停用时只撤回本插件写入且未被其他组件修改的值，恢复原进程身份。测试使用假注册表，开发过程未把修复写入正在运行的 Salt。
- Windows 可能缓存旧会话名称，升级后需完全退出并重启 Salt。实际系统卡片是否消除「未知应用」仍是安装验收项，不把模拟注册测试等同于系统显示验收。
