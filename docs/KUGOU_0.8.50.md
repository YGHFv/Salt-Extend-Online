# 0.8.50 酷狗音乐接入与加载修复

酷狗音乐协议参考 `umr-xiaomai/kgka_Music_hl`，固定提交
`6463ebf31016e053f726ae31cf9670d8bf76edd6`。沿用此前 NeriPlayer、MusicOne、
mygo-qyin 和 MineRadio 的目录、登录及播放架构。来源和适配脚本指纹见
[第三方声明](../THIRD_PARTY_NOTICES.md) 与 [reference-lock.json](../reference-lock.json)。

## 酷狗音乐在线接入

增加第五平台的侧栏／顶部入口、启动首页、默认栏目和 128／320／FLAC 音质偏好。
支持匿名推荐、歌曲搜索、扫码登录、我的歌单、收藏歌单、歌单分页、整单读取、
Salt 原生播放队列及歌单保存和重启恢复。

请求使用参考项目的第三方 KA Music API（`music.api.hoilai.cn`）。
二维码接口返回的 `X-Kg-Session-Id` 在轮询、账号验证和后续账号请求中保留，
本地继续用 Windows CurrentUser DPAPI 保存；退出和账号更换撤销旧会话。
凭据仅发往固定 API，不发给图片或音频服务器。

上游推荐固定返回 35 条，搜索固定返回 30 条，与 Salt 的 20 槽接口页和
可配置界面窗口分别转换、缓存，避免跨页丢歌。我的歌单和收藏歌单来自同一接口，
先按类型筛选并汇集，再应用界面分页。全局 `collection_*` 歌单 ID 保持字符串形式。

播放先读取指定 hash 对应的权限及完整音轨大小，再校验返回媒体 hash、
CDN 地址和 Range 总长度。偏好音质不存在时请求实际可用的基础音质。
拒绝试听、大小不匹配及平台验证失败，不提供会员或风控绕过。
KRC 逐字偏移转换为绝对时间，候选 `adjust` 与歌词 `offset` 各叠加一次，
沿用 Salt 原生歌词页。

## 网易云私人歌单

实际接口在同一歌单对象中先返回 `"creator":null`，随后又返回 creator 对象，
原有严格 JSON 解析在进入目录映射前报 `NET_DISCOVER/RESPONSE`。
仅私人推荐歌单端点允许这一特定重复字段，其余 JSON 解析仍拒绝重复字段。
补齐嵌套推荐列表和字符串歌单 ID 的兼容。

## 网易云音乐漫游与 QQ 猜你喜欢

两项推荐接口返回可变的小批次，而界面此前尝试填满 30 条，连续请求多个批次后
才显示结果。现在每个用户请求页面直接显示一次接口返回的批次；下一页或加载更多
才请求下一批。同页回访读取缓存，刷新、账号更换和退出清理缓存。
网易云重复或空批次结束加载，取消及撤销禁止旧结果回填。

音乐漫游使用网易云私人 FM 接口，当前不实现官方客户端完整的漫游模式或无人操作续播。

## Apple Music 客户端

修复 Store 应用启动方式：优先执行别名，否则从实际安装包 manifest 或 StartApps
读取 AUMID，由 Explorer 激活 AppsFolder。后台进程没有窗口时仍尝试唤起窗口，
并区分未安装、启动失败和窗口等待超时。

歌曲导航优先使用官方客户端 `/url`，无别名时使用 `music:` 协议。
辅助进程等待时限调整为 75 秒，覆盖客户端冷启动、导航和播放状态确认。
点播仍通过官方客户端及 SMTC 验证曲目与状态，单纯打开页面不算播放成功。
