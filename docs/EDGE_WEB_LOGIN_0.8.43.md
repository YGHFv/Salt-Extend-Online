# Edge 网页登录启动兼容 0.8.43

## 问题与复现边界

2026-11-09 有用户反馈已安装 Microsoft Edge，但点击官方网页登录无法打开窗口。未取得该用户机器的系统信息和错误码，因此不把本机复现的缺陷认定为其唯一原因。

本机在独立 Windows PowerShell 子进程中清空 `ProgramFiles(x86)`，执行原有候选目录构造，稳定得到 `Join-Path` 的 `ParameterArgumentValidationErrorNullNotAllowed`：候选数组采用立即求值，首个目录为空时提前退出，后面的有效安装目录不会被检查。原实现还只查三个固定目录，不支持注册在自定义目录的安装；启动、调试连接、策略和辅助进程错误大多统一变成 `WEB_FAILED`／`RESPONSE`。

## 修复

- 候选目录空值安全，补充 `ProgramW6432` 和 .NET 系统特殊目录；单个无效目录不阻断其他候选。
- 固定目录之外查询 HKCU／HKLM 的 Registry32／Registry64 App Paths 默认值；不修改注册表，不依赖默认浏览器关联。
- 只接受实际存在的绝对 `msedge.exe` 路径；支持空格、Unicode、单引号、外围双引号及环境变量。拒绝相对路径、其他程序、附带启动参数和控制字符，不通过 shell 执行注册值。
- 冷启动 `Browser.getVersion` 安全管道连接由 8 秒延长到 25 秒；每个 CDP 请求按单个总时限计时，消息流不能不断延长等待。
- 常规 CDP 请求保持 8 秒；浏览器关闭请求限制 2 秒。官方网页轮询 250 秒，为冷启动、最后请求和清理预留余量，Java 网页操作仍限制 5 分钟，辅助进程限制 290 秒。
- 网易云设备环境辅助进程上限从 55 秒增加到 70 秒，扫码整体仍受原有 70 秒请求限制；不生成假设备标识、不使用空设备令牌。
- 检查 `UserDataDir`、`RemoteDebuggingAllowed`、`DeveloperToolsAvailability` 的强制注册表策略；存在配置目录覆盖或调试禁用时安全拒绝，策略读取被拒绝也不冒险启动。不修改或绕过策略。
- 保留临时目录的用户私有 ACL、代码文件短命令加载、继承匿名管道和精确子进程生命周期；不读取默认浏览器配置、已有 Cookie 或账号，不开放 TCP 调试端口。
- 启动连接失败后直接清理，不再额外等待一个无效的关闭 CDP 请求。

## 安全错误码

网易云官方网页登录使用 `NET_WEB`，QQ 音乐使用 `QQ_WEB`，网易云扫码设备环境使用 `NET_DEVICE`。三个入口保留相同原因，不把设备环境和 QQ 的浏览器错误吞成通用验证失败。

| 原因 | 含义 |
| --- | --- |
| `BROWSER_MISSING` | 未找到可用的正式版 Edge 安装路径 |
| `BROWSER_LAUNCH` | 已找到 Edge，但系统拒绝启动 |
| `BROWSER_EXIT` | 启动后在连接建立前退出 |
| `BROWSER_CONNECT` | 调试管道／协议不可用 |
| `BROWSER_TIMEOUT` | 冷启动连接超过 25 秒 |
| `BROWSER_POLICY` | 策略禁止调试或覆盖独立配置，或无法安全读取策略 |
| `HELPER` | Windows PowerShell 辅助程序缺失、无法启动或异常退出 |
| `PROFILE` | 无法建立受保护临时目录或新浏览器配置 |
| `TIMEOUT` | 网页或辅助程序整体超时 |
| `CANCELLED` | 登录窗口关闭 |

UI 只显示固定原因及建议，不展示原始异常、安装路径、注册表值、stderr、Cookie 或签名 URL。已找到 Edge 却无法启动时不会再建议重复安装来代替诊断。

Microsoft 官方 `RemoteDebuggingAllowed` 文档说明该策略约束 `--remote-debugging-pipe`；`UserDataDir` 文档说明策略可以覆盖命令行指定目录；`DeveloperToolsAvailability` 文档说明其约束直接 CDP 连接。本轮只读取这些配置并安全拒绝，不尝试修改用户系统。

## 验证

独立子进程测试使用本次临时目录的空 `msedge.exe` 文件和进程内注册表读取替身，不写真实注册表、不修改父进程环境：

- 缺失安装目录环境变量、空候选、默认目录和自定义 App Paths 发现。
- 空格／Unicode／引号／环境变量展开，以及附带参数、相对路径、错误程序、控制字符拒绝。
- 策略拒绝、读取失败、已找到但不可执行、重复配置拒绝。
- 连接初始退出、协议错误、冷启动超时、成功和固定错误脱敏。

实际安装 Edge 的隐藏无网站测试只打开 `about:blank`，验证匿名管道、合成网易云／QQ Cookie、官方设备脚本的合成映射与来源拒绝。清空子进程所有相关环境变量后仍能正常启动实际 Edge。用户取消和辅助程序整体超时均清理本次临时配置。没有真实账号、外站导航、可见窗口或宿主队列操作。

最终验证通过：

- 48 次子进程内 Edge 路径／策略／启动／连接检查。
- 实际隐藏 Edge 安全管道、合成 Cookie／设备脚本、取消／超时和临时配置清理测试通过；最终生产资源优先加载，无测试替身进入模组。
