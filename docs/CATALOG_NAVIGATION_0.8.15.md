# 0.8.15 返回、布局与兼容检查

## 返回与配置

- 标题行提供 40 dp 返回图标，不额外占用一行。
- 对 `Navigator.back()` 安装 before hook。只有当前原生路由属于本插件、页面可见、同一 navigator 且存在内部历史时消费返回；合集、收藏夹、UP 主页共用控制器历史。
- 原生播放页展开时让 Salt 先收起，其他页面／对话框／无内部历史时不拦截。插件关闭时解除 hook。实际宿主 Advice 的 void 方法跳过能力通过变换测试验证；不依赖无法替换返回值的 after hook。
- 使用宿主 ConfigHelper 独立保存 `catalog-ui.json`，键为 `layout.bilibili`、`layout.netease`，值为 `SINGLE`、`DOUBLE`、`CARDS`。缺失／无效值回退单列，保存失败恢复旧值并显示操作错误。退出登录不清除布局，保存布局不修改音质或登录配置。

## 布局

表头和行复用标题、次要信息、右侧统计单元格的权重、边距与封面宽度。合集内不重复显示合集名；发现／搜索没有可靠归属时隐藏整列。标题、作者限行，普通列表作者与时长使用同一行高，避免一侧多行导致错位。

卡片标题预留两行、作者一行。播放量位于封面左下角、时长位于右下角，两者白字覆盖透明到黑色渐变。源封面不改写，四种比例／裁切设置继续生效。UP 视频卡片在作者下显示日期。

## UP 视频排序

- 最新：签名 `/x/space/wbi/arc/search`，`order=pubdate`。
- 播放量：同一接口，`order=click`，分页和缓存 key 保留排序值。
- 逆向：最早发布优先，不是仅反转当前页。读取第一页获取总数，再读取覆盖目标区间的一到两页，按原始位置截取、反转，最后过滤不可播放内容。45 条的第一页是第 45–26 项、第二页第 25–6 项、第三页第 5–1 项。
- 总数改变时拒绝混合结果，提示刷新；无总数或超过 10,000 条不伪造完整逆向。每次最多三页目录请求，复用同一验证会话，不逐条补详情。
- 排序针对 UP 的“视频”页；“合集”页保持官方顺序，不将合集播放量与视频量混为一谈。
- “更新时间”使用 `created` 发布日期，按北京时间展示，不声称是编辑时间。播放量来自列表接口；缺失日期／播放量显示 `--`，未知时长显示 `--:--`。

## 不再锁定版本

移除运行时 `1.19.3`／`Steam` 必须相等的判断，也不再把类文件 SHA-256 变化作为运行拒绝条件。保留类、构造器、方法参数与返回类型、关键字段及页面对象形状等能力检查。原生 UI 与播放能力分开启用，播放适配失败不再连带隐藏可用侧栏。

项目并非只调用官方稳定接口：原生导航、主题、播放器队列还存在内部／混淆名称绑定。结构改变时相关功能仍可能不可用，不能承诺所有升级都免适配。测试和编译仍使用 1.19.3 基线指纹与 ABI 验证，保留基线资源用于开发审计，不是用户运行时版本锁。

## 验证

- `CatalogNavigationContractTest`：临时配置落盘／重建、平台独立、失败回滚；真实 Salt Navigator 的内部历史、平台切换、不可见、展开播放页、根返回，不操作安装配置。
- `CatalogPresentationContractTest`：45 条非整页的逆向跨页边界、播放量参数、查询顺序保持、日期和播放量，以及原有缓存／并发／导航。
- `PlaylistRenderTest`：740 / 580 / 420 dp 和 1x / 1.5x，未合并语义节点的作者／时长、日期列、返回同一行、封面角标范围、UP 排序以及原有搜索／播放。
- `NativeHookTransformTest`：实际宿主 Advice 变换后 before 跳过 void 原方法，取消 hook 后原方法继续执行；合成 bridge，不注入正在运行的播放器。
- 兼容回归验证不同版本／渠道、不同字节资源但相同类结构可用，所需类缺失仍拒绝；原生字段顺序继续验证。
- 原有预加载回归存在竞态：缓存达到 800 字节可能只是前两项完成。改为同时等待第三项解析／请求完成，不改生产预加载逻辑。

测试仅使用合成内容、假 HTTP、离屏原生组件，没有读取、编码或回传用户截图，没有真实登录或音频播放。实际侧键硬件与其他 Salt 版本仍需更新后本机验收。

本地完整构建通过 49 个插件测试程序、70 项 core 检查和 6 项 inspector 测试；宿主基线校验覆盖 21 个类和 255 个编译后 ABI 引用。独立 host-free suite 同样通过，日志未发现后台 Compose／线程断言异常。
