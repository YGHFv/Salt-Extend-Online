# 0.9.9 视频控件隐藏与输入锁修复

视频模式下，鼠标静止后文字隐藏，底部胶囊背景仍然残留，窗口和播放
控件点击也可能失去响应。此前底部回归仅统计浅色文字／图标像素，
没有覆盖单独绘制的背景，也没有在会话锁被占用时验证输入回调。

原生 Windows 窗口命中测试和播放条状态读取曾获取视频会话锁。
视频工作线程持有同一把锁时会调用 `MouseInfo`，依赖 Windows
窗口线程；窗口线程再次执行命中测试等待会话锁时，可能形成互相等待。
现在这些输入路径不再获取视频会话锁，指针活动和隐藏状态更新也不再
依赖该锁。窗口按钮的区域引用使用不可变列表发布，避免跨线程遍历
正在修改的列表。

播放条的可见状态使用透明代理：视频展开时读取为可见，原生鼠标
事件仍写入原有状态；普通模式读取原有状态，插件关闭时恢复原始
状态对象。读取操作不再写入 Compose 快照状态。保留原生方法的
返回路径，因为 Salt 1.19.3 的普通方法 advice 在 `setResult` 后
会跳过原方法，但不能正确传递非默认返回值。

底部胶囊背景是 MainSurface 中单独的、仅带 Modifier 的 Box。
现在该调用与播放控件共用三秒计时器，隐藏时一起移除，恢复时使用
原有 Modifier 绘制，继续保留原生位置和展开／收起动画。

回归在真实宿主转换器和 Direct3D 窗口中检查隐藏后的胶囊中央区域
所有颜色，以及底部控件是否已退出语义树；外侧仍由宿主播放页的
裁剪几何控制。新增持锁回调检查可在旧版稳定复现超时，并检查新实现
读取时不会改写原生状态。恢复并重新展开后，鼠标实际点击原生
播放／暂停按钮，确认点击来自原生按钮而不是视频画面的单击回调。
视频暂停、进度同步、切歌、取消加载、窗口缩放和异常回收沿用现有回归。

测试使用合成视频和隔离宿主配置，不需要用户账号或平台音轨。
