# Salt 宿主适配约定

## 当前结论

SPW Workshop API `0.1.0-dev22` 提供播放控制，不提供在线媒体装载。
`SaltHostBridge` 是**本项目自定义接口**，不是官方扩展点。
当前实现明确返回零项能力，`enqueue()` 抛出 `UnsupportedOperationException`。
预览主类不 Hook 宿主、不注册在线页面、不假造媒体，不生成可播成功提示。

更新：已核对用户本机 Steam 1.19.3，并生成被动检查 profile；队列、原生流、封面入口
及无播放副作用的媒体构造测试见 [实际宿主核验](HOST_AUDIT_1.19.3.md)。
检查器不会把仅通过签名检查的候选能力设成已完成在线播放。
随后已完成实验性的流适配、私有传输和播放会话组装，见 [进度与边界](PLAYBACK_PROGRESS.md)。
主类仍不自动安装这些组件，`SaltHostBridge` 仍不宣称实播能力。

版本参考：API commit `4f5f164ccf2fb2563efa18afeb9ddaa611978a88`。
Hook 的版本注解参考宿主 `1.19.0`，这不是“所有 1.19.0 安装包都已验证兼容”的承诺。

## 1. 优先策略

1. 若官方新增媒体提供者接口，优先用官方 API，减少高危权限和混淆维护成本。
2. 若目标 Salt 当前已有内部在线媒体入口，基于用户提供的对应安装包做可验证的适配 profile。
3. 若宿主不能承接该媒体，不把第三方引擎播放或下载整曲冒充 Salt 原生在线播放。

已只读检查本机安装的 WebDAV 0.2.2 包，但没有取得它的公开源码或可复用代码许可。
其线索均需交叉核对实际宿主，不能未经验证写它“必然 Hook 某类”。
`.strm`、伪装本地文件、自定义 URI、回环 HTTP、数据库直写都不能未经验证成为默认方案。

## 2. Profile 约定

```text
HostProfile
  id
  os / channel / exactSpwVersion
  apiVersion
  applicationJarSha256 / relevantClassFingerprints
  mediaFactoryBinding
  queueBinding
  streamBinding
  coverBinding
  uiBinding?
  testedLyricsFormats
  testedPlaybackFormats / rangeSupport / headerSupport
```

这些字段描述未来检查流程；没有填入猜测类名的“示例 profile”。
Windows/Linux 同版本可能不同混淆；Steam/其他渠道的实际 profile 独立核验。
版本号相同但关键二进制不同不能跳过校验。

## 3. 必须验证的契约

| 入口 | 验证问题 | 验收 |
| --- | --- | --- |
| 媒体创建 | 能否携带稳定 ID、标题、艺术家、时长、封面和逻辑源？ | 不依赖假文件；不污染本地扫描 |
| 入队 | 队列修改的类型、线程、快照和生命周期？ | 支持当前播放／下一首／追加；切歌不丢逻辑身份 |
| 取流 | 何时解析？能否异步返回？是否支持 Header／备用 URL？ | 过期重新解析；无主线程网络阻塞 |
| 流格式 | DASH 单音轨、FLAC/AAC 等能否被 Salt 内核识别？ | 原音频播放及拖动，无隐式整曲转码 |
| 请求头 | Referer、账号凭据、Range 的真实作用域？ | 必要头到正确域；跨域不泄漏 |
| 封面 | 附加元数据／封面加载器／合法写入入口？ | 播放页、队列、通知更新同身份，不只插件页有图 |
| 歌词 | 支持哪些输入格式与翻译／音译表达？ | 回读 Cell 时序与原始 fixture 一致 |
| UI | 可选注入调用点是否唯一，Compose 编译版本是否一致？ | 不覆盖本地页；默认参数调用限制已测试 |

公开普通方法 Hook 不支持 `suspend`、native、abstract、构造函数或内联调用。
只能在已验证的实际普通方法上注册，不能通过虚构方法绕过限制。
如果只能 Hook 同步调用，网络必须在它之前异步准备，或者找到合法的异步完成入口；
不能在 UI 线程同步等取流。没有合法错误／缓冲表示就禁用该能力。

## 4. 能力而非版本猜测

未来桥接层扩展 `ONLINE_QUEUE`、`STREAM_RESOLUTION`、`COVER_PUBLICATION`、`ONLINE_PANEL`。

- 只在对应入口解析、指纹和最小联调全部通过后声明能力。
- 不能因 `CLASS_TRANSFORM` 被授权就把所有能力设为 true。
- 缺在线页面时可以单独窗口；缺封面发布时明确标记部分功能；缺入队或取流时禁止播放按钮。
- 未知宿主版本只保留真正稳定的配置／歌词后备能力，不模糊扫描所有相似方法并试着 Hook。
- 用单曲联调探测验证接口，不在启动时做用户库批量写入。

## 5. 稳定歌词扩展与在线项映射

公共 `onBeforeLoadLyrics(mediaItem)` 适合仅对**本插件映射的在线项**提供已解析词，
以实现指定 Neri 来源而不被 Salt 默认来源覆盖。
其他插件／本地项返回 null，不抢占已有用户歌词。
如未来支持通用本地词图后备，则另用推荐的 `onAfterLoadLyrics`，不修改本地音频标签。

歌词回调的新增 `duration` 等元数据可能是缺省值，不能把 0 当已查询过的真实时长。
优先查自己的 `hostMediaId ↔ TrackKey` 映射与源平台元数据，不能用回调不足字段强配歌词。

异步网络可以预取；歌词回调运行于 IO 线程，按预算读取缓存／必要加载，取消与错误明确区分。
结束前检查同 track/account/preferences/revision 的发布票据。
`onLyricsLinesUpdated` 是读取已解析完整列表的通知，不是向宿主注入时间轴的 API。

## 6. 权限与生命周期

- 原生 Hook 路径申请 `CLASS_TRANSFORM`，注册前实际查询权限并处理拒绝异常。
- 读取 Salt 曲库／当前快照才申请 `LIBRARY_READ`，拒绝查询可能以失败 stage 或同步异常返回。
- 不为不存在的写入口申请 `LIBRARY_WRITE`；不在预览阶段申请未使用的高危权限。
- 注册在 `start()` 调用线程完成；后台任务只做网络／解析，不通过其他插件传递权限身份。
- profile 失效、权限撤销、插件停用时不再发起新操作，释放窗口与监听、取消任务、失效发布票据。
- Hook 自动清理不等于插件自有 executor、缓存、配置 listener 自动释放。
- 停用后的已开始回调可能完成，必须自行阻止结果重新更新已关闭页面。

## 7. 完成 P0 所需材料

最低要求：

- Salt 的准确版本、OS 和渠道；对应安装包／应用 JAR。
- 本机最小试听环境，确认播放器本地音频正常。
- 用户主动授权的测试账号，仅限当前平台允许取得的公开／自有内容。

可选：参考 WebDAV 插件公开源码或用户合法取得的 `.spmod`，用于确认同类在线媒体入口。
不读取 Steam 账号凭据，不通过未经授权的方法获取隐藏 Workshop 内容。

P0 交付应包含 profile、最小样本、播放／拖动／封面／歌词实测记录、权限拒绝及卸载回归。
未通过前保持当前不可用桥接实现，不能把工程可编译当“在线播放已经实现”。
