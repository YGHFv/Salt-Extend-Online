## 本轮功能

配置中“打开本机听歌桌”在默认浏览器打开私有回环页面，不嵌入另一套音频播放器。
启用插件和打开页面都不自动查询平台；只有点击栏目才请求列表。

| 栏目 | 网易云 | B站 |
| --- | --- | --- |
| 发现 | 匿名推荐歌单，最多20个；可打开公开歌单 | 暂无匿名发现入口，明确失败，不伪造推荐 |
| 我的歌单/喜欢 | 当前账号创建的歌单；creator UID与账号相同且specialType=5标识喜欢歌单，不猜第一个列表 | 当前账号创建的收藏夹 |
| 收藏/订阅 | 当前账号订阅、且不由自己创建的歌单 | 当前账号订阅的收藏夹；混入的type21合集展示为暂不支持 |
| 列表内容 | trackIds分页，每页最多20个，按原始ID顺序批量读详情；付费/缺失/失效曲目禁用 | 收藏夹资源分页，视频默认准备P1；失效/非视频项禁用，分P可用配置中的明确链接 |
| 播放 | 标准免费完整音轨，保留0.5费用/试听/时长/长度门禁 | 高档偏好DASH，保留付费/预览/权限/CDN门禁 |

个人歌单/收藏需要本插件扫码账号并再次向平台验证UID。用户不能在本机动作中指定任意UID或CDN地址。
所有接口都是读操作；没有新增收藏、取消收藏、点赞、修改歌单或平台账号写入功能。
没有搜索、整单批量入队、自动下一首取流、自动租约续期或会员/单购播放能力。

## 播放流程与原生所有权

```text
明确加载列表 → 点曲目“准备音轨” → 后台解析/bytes=0-0 → 准备完成
  → 回Salt明确启用实验适配 → 再明确确认播放
  → 独立账号播放会话 → 原生媒体项/私有流映射 → 原生addToPlay
```

- 列表读取、选择和后台解析从不提交队列；播放不自动启用Hook。
- 配置也提供“准备当前配置B站/网易云音轨”与“确认播放当前已准备音轨”按钮，不依赖听歌桌。
- 每次准备产生独立播放确认能力；提交尝试前消费，只允许一次。拒绝、连接丢失或宿主错误后不自动重试，避免重复入队。
- 原生媒体ID与私有路径每次准备都新建，逻辑TrackKey另保留；不让宿主按旧队列ID复用新账号资源。
- 一个已明确启用的runtime拥有Hook、adapter和回环监听；账号session共享这些资源，仅清理自己注册的路径/租约。
- 登录、退出、账号替换会清理对应平台会话，取消旧请求与准备结果；另一个平台的session、测试音及其他模组不因单平台退出被拆除。
- 账号有效性闭包捕获提交时的具体账号对象/平台，不引用以后选择的账号；旧匿名流也不能采用新的登录。
- 过期准备不能再提交。旧过期映射在后续准备时回收，单session最多64项、runtime最多4个scope；不自动续期或重绑旧队列项。
- 原生addToPlay返回只表示异步命令调用完成，不证明宿主接受、开始解码或发声。未接播放接受/错误观察器。
- 退出/停用撤销本插件资源，但宿主已有缓冲可能短暂继续；不调用全局Unspecified abort，不清空队列、不恢复旧歌曲。

## 本机页面边界

本机127.0.0.1随机端口、256-bit能力路径；GET仅页面和status，不能改变队列或浏览平台。
动作仅一个固定POST路由：精确Host与Origin、nonce CSRF请求头、application/json、4KiB请求体、重复头/歧义/异源拒绝。
动作字段白名单；只接受栏目/翻页/当前可见行token/当前准备token，不能导入Cookie或指定任意资源。
行token跟随可见页revision，新查询、翻页、账号变化、过期和停用都会失效。
浏览器状态响应按请求序号应用，旧响应不能覆盖较新的状态；连接关闭会清除可见列表和准备标题。

CSP只允许nonce脚本/样式与本机fetch，no-store/no-referrer/nosniff/frame-ancestors none，无外部字体/图片/CDN资源。
服务器2个worker、4个队列位、请求8秒总期限、页面最多30分钟；平台读取各单worker/单待执行槽位，30秒操作期限。
网页只获取显示元数据与局部动作token，不接收账号Cookie、QR登录key或签名音频URL；远端标题仅通过textContent渲染。
私有列表只在内存，不写浏览器存储/磁盘缓存，不读浏览器账号。回环能力不是防御同一Windows用户下恶意进程的安全边界。

## 参考协议

NeriPlayer仍固定为`fd7fdb757821fda7a62aee3a2b7cecf3a4b8bfe0`。

- 网易云推荐`/weapi/personalized/playlist`、个人`/weapi/user/playlist`，WEAPI AES/RSA与平台__csrf使用参考流程。
- WEAPI需要时只做一次有界主站会话预热，__csrf缺失就停止；不伪造CSRF、设备令牌、账号凭据或自动绕过风控。
- 歌单`/api/v6/playlist/detail`使用API form POST，保留trackIds；本插件n=0/s=0，单页最多20个歌曲ID用GET详情补齐，原始ID顺序不被返回顺序覆盖。
- B站使用`/x/v3/fav/folder/created/list`、`collected/list`、`/x/v3/fav/resource/list`，当前账号mid与分页参数固定；type21不当普通收藏夹调用。
- 新POST工厂仅开放三个固定只读目录端点；登录/取流仍各用独立工厂，媒体传输仍仅GET/HEAD。

## 手动验收

1. 手动导入0.6实验包；同ID旧版本先停用，授权class-transform，降低系统音量。不自动安装或启用。
2. 保持“记住登录”默认关闭，明确扫码并在官方手机App确认。先查看账号已校验状态，不提供Cookie或QR key。
3. 打开听歌桌，分别明确点发现、个人、收藏；翻页，打开列表。检查喜欢歌单标识、订阅过滤、失效项禁用和P1说明。
4. 点一个合法免费曲目准备，确认没有修改当前播放；回Salt启用实验适配，再在页面确认播放或点击配置播放按钮。
5. 检查是否出现原生队列项、是否实际发声、暂停/seek/设备变化；仅看到“Submitted”不能判定成功。
6. 退出一个平台、换账号、改配置、过期、停用；旧行/准备不能再用，另一平台/其他模组不被拆除。队列遗留项手动删除。

这是单曲明确提交预览，不是整张歌单自动播放的最终验收版本。
