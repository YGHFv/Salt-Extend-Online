# QQ 音乐接入（0.8.38）

参考固定版本 NeriPlayer `fd7fdb757821fda7a62aee3a2b7cecf3a4b8bfe0`，
使用当前 Bilibili／网易云的 Salt 原生页面，不复制 Android UI，也不增加第二套播放器。

本页记录 0.8.38 的验收边界；登录优化与 QRC 逐字歌词已在 [0.8.39](QQMUSIC_LOGIN_QRC_0.8.39.md) 接入。

## 已接入

- 原生侧栏及顶部快捷入口、绿色品牌图标、侧栏显隐、Salt 启动首页、平台默认栏目。
- 发现歌单、收藏（创建歌单及喜欢）、订阅歌单、歌曲搜索、公开及登录后歌单读取。
- 原生标题栏、账号头像菜单、搜索、卡片／单列／双列、分页、完整合集筛选排序、全部播放。
- 双击播放、原生插播菜单、添加到 Salt 歌单、稳定 song MID 持久化、重启重新解析、预加载与缓存。
- QQ 官方二维码、账号校验、Windows CurrentUser DPAPI 保存及恢复；取消、过期、退出、权限撤销均清理会话。
- 官方网页 QQ／微信登录及手动验证复用独立临时 Edge、匿名管道和已有清理流程，不读取日常浏览器配置。
- 标准、较高、极高、无损、Hi-Res、全景声 5.1／7.1、杜比、DTS:X、母带偏好；当前账号无权限时只尝试合法低档。
- 原曲普通 LRC 与翻译，按相同时间戳交给 Salt 原生歌词页，原文和翻译不串平台。
- 默认关闭的自动换源复用网易云已接入的 NeriPlayer 歌名／歌手／时长／分 P 匹配；只在歌曲完整音轨不可用时使用独立登录的 B 站公开音源，保留 QQ 身份、元数据、封面和歌词。

## 安全与差异

- QQ 二维码由上游返回图片，直接展示图片，不把图片地址再次编码成二维码；有效期 2 分钟，必须用手机 QQ 扫描。
- OAuth 仅接受固定 HTTPS check_sig/login_jump/callback；检查随机 state、唯一授权 code、账号身份，不自动跟随任意重定向。
- 临时 QQ OAuth Cookie 与音乐账号 Cookie 分离；音乐账号仅限 `y.qq.com` 及其子域，CDN 不接收账号 Cookie。
- 音频仅允许 QQ 官方 HTTPS CDN，校验 song MID、文件名、vkey、非 RS02 试听、上游完整文件大小及真实 Range 长度。
- 登录／网络／风控失败不进行匿名回退或自动换源，不复刻 NeriPlayer 的试听兜底。
- 微信使用官方网页登录，不移植 Android QIMEI 设备伪装协议；逐字 QRC 解密不在本次接入范围，保留官方普通歌词和翻译。
- 公开歌单接口返回整表，只在完整响应内切页；登录歌单按 20 项分页，全量提交检查计数和去重，最多 10,000 首。

## 验证边界

- 新增 QQ QR/OAuth、目录、身份、音质、完整音轨、歌词、持久化和双账号换源合成测试；现有三平台页面、右键菜单、侧栏及首页回归共用真实宿主类。
- 最终全量构建通过 73 个契约测试类；QQ 协议 85 项、QR/OAuth 28 项、原生页面渲染 279 项、三平台队列封面 359 项检查通过。11 个无宿主契约测试、原生 UI ABI 和安装包隔离／配置验证也通过。
- 显式匿名实网检查已验证发现／搜索各 20 项、公开歌单完整读取 555 首、歌曲详情、封面地址和非空歌词，以及官方二维码图片获取及待扫描状态。未授权音轨正确拒绝，不启动 Salt 音频设备。
- 真实 QQ／微信账号扫码、会员各档、私有歌单及实际连续发声仍需用户登录现场验收；合成测试通过不代表这些已验收。
- 安装包在 `plugin/build/libs/`，不自动替换已安装版本；升级后完全退出并重启 Salt。
