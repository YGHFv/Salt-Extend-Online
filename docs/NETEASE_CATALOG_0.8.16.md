# 0.8.16 网易云歌单与封面兼容

## 歌单读取

用户报告 `NET_PLAYLISTS/RESPONSE`。没有获取用户账号或原始响应，因此无法断言唯一原因；以下旧实现问题已通过合成响应复现并修复：

- 强制读取 `creator.userId`，创建者缺失或结构不同会导致整页失败。现在优先使用顶层 `userId`，其次使用创建者 ID；身份缺失时参考 `subscribed` 归类，不猜测具体作者身份。
- 数字字符串、可选歌曲数量格式异常不再导致整页失败。创建／订阅身份明确时仍按账号 ID 区分；无效 ID、空名称、非对象与重复项只跳过当前项。
- 名称与作者的换行／控制字符清理为空格，长度受限；这只是展示层容错，不放宽身份验证、API 错误或权限校验。
- 接受 `playlist`／`playlists`，以及明确返回的空列表；缺少列表字段或错误根结构仍报错，不将登录／风控失败伪装为空列表。
- 兼容布尔、数字及字符串分页标志；上游额外返回的条目不导致整页报错，仍按请求的 20 条原始窗口分页。分页数量不取筛选后的可见行数。没有总数时保留 `?`，不为计数抓取整库。
- 详情接口返回多于请求数量的内嵌曲目时，仅提取目标窗口，并继续验证曲目 ID 是否属于当前歌单、是否重复；仍保留 JSON 2 MiB、最多 10,000 首等边界。

## 列表缺图而播放有图

- 旧版列表只允许 4 MiB 图片，播放允许 8 MiB；现在二者统一 8 MiB 原图上限。列表仍只保留最长边 480 像素缩略图，播放最长边 1024 像素，不增加输出缩略图或缓存项数。
- 歌单封面依次尝试 `coverImgUrl`、`picUrl`、`coverUrl`，空值／不支持地址不再阻止备用字段。曲目兼容 `al` 与 `album`。
- 内嵌曲目具有空字符串或不可用封面地址时，不再当作完整详情跳过补查；复用现有歌曲详情批次获取完整元数据。
- 对网易云当前可见曲目／歌单，缺图时或原图下载失败后，可异步读取一次歌曲／歌单详情补图。歌单请求 `n=0`，歌曲只请求自身 ID；不请求音频 URL，不启动播放，不额外抓取整张歌单。
- 仍由原有三路封面 worker 调度，按行 token 缓存成功或失败；同一行不循环重试。离开列表、切账号或失去权限后，过期查询不能发布到新页面。正常已有封面不补查。
- HTTPS 域名白名单、无 Cookie 图片下载、图片格式／尺寸／字节限制、账号验证、返回 ID 校验均保留。官方权限／网络故障或没有任何可用原图仍可能显示占位图；可以显式刷新后重试。

## 回归

新增 `NeteaseCatalogCompatibilityTest` 覆盖混合歌单字段、换行、缺创建者、订阅、分页、内嵌曲目超页、空／非法封面字段、详情补图身份及异步账号撤销。扩展封面测试生成一张 4–8 MiB 合成 PNG，分别验证有／无 Content-Length 的列表与播放解码，以及超 8 MiB 拒绝。

测试只使用假 HTTP、合成账号／图片与实际宿主 ABI，不读取用户截图，不登录真实账号，不播放音频。其他账号的真实返回仍需更新后验收。

完整本地构建通过 50 个插件测试程序、70 项 core 检查和 6 项 inspector 测试，包含 28 项本次网易云兼容检查、125 项封面检查；host-free suite 同样通过。构建日志未发现后台断言或 Compose 异常。
