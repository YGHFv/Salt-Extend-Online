# Salt Extend Online

在 Salt Player 原生界面中浏览、搜索和播放 Bilibili / 网易云 / QQ 音乐内容，复用 Salt 的播放队列、输出设备、音效和歌词页，不嵌入另一套播放器。

Steam 创意工坊：[Salt Extend Online](https://steamcommunity.com/sharedfiles/filedetails/?id=3835352817)

项目地址：[YGHFv/Salt-Extend-Online](https://github.com/YGHFv/Salt-Extend-Online)，已通过官方 `Plugin-Open-Source-Url` 字段内嵌到模组包。

**当前版本：0.8.48-auth-flow · 开发预览**。使用官方插件接口并包含部分原生 UI／播放内部绑定，需要 `CLASS_TRANSFORM` 权限。移除运行时严格版本、渠道及类文件哈希锁定，改为检查所需接口结构；某项接口缺失时停用对应能力。当前实际回归基线为 Windows / Steam Salt **1.19.3**，不承诺所有未来版本自动兼容。

自动构建／发版：可信 `main` 推送先跑 GitHub 离线回归，再由本仓库专用 Windows runner 完整回归和打包；提升版本号后自动发布 `.spmod` 与 SHA-256 的开发预览 Release。同版本不覆盖已发布文件。外部 PR 不在本机运行，部署与维护边界见 `docs/SELF_HOSTED_RELEASE.md`。

## 使用

1. 在 Salt 模组管理中导入 `plugin-io.github.yghfv.saltneri.online-0.8.48-auth-flow.spmod`，授予所需权限。同 ID 旧版不要同时启用。更新后请完整退出并重启 Salt，确保原生界面及播放绑定使用新版。
2. 点击侧栏 Bilibili / 网易云 / QQ 音乐，首次进入自动加载「发现」。平台间切换保留各自的列表、分页、筛选和滚动状态。
3. 在平台页登录；登录后点击右上角头像切换账户或退出。网易云扫码需要已安装的 Microsoft Edge，在后台独立临时环境中准备官方设备令牌；失败或遇到风控时可使用「官方网页登录」手动验证。两种方式均不读取浏览器已有账号。
4. 单击合集或收藏夹打开，双击曲目播放。合集标题栏提供返回、搜索、全部播放、布局、排序；全部播放替换整个 Salt 队列，遵循当前顺序／随机模式。三平台未设置布局时默认卡片，点击布局图标按「卡片 → 单列 → 双列 → 卡片」循环，分别记忆，不再弹出选择菜单。
5. 右键视频或歌曲，使用 Salt 原生「添加到队列」选择当前播放后／上次插播后／队列末尾；「添加到歌单」选择 Salt 歌单，也可打开原生新建歌单页。添加不打断正在播放的歌曲。刷新按钮移至右上角工具栏。

播放只使用官方账号可访问的完整音轨，不提供会员、付费或风控绕过。B站搜索需要登录；网易云匿名发现／搜索可能被服务端要求登录。失效内容不显示，合集内筛选不改变「全部播放」覆盖整个合集的语义。

本轮移除合集整理提示、修复播放准备完成后的列表闪动，错误改用官方 toast；标题及操作栏固定在滚动区域外。播放时在原生加载完成后确认一次显式播放意图，后续暂停、切歌或权限撤销会取消，不做定时强制恢复。新增侧栏功能按钮显隐与「隐藏侧栏」设置，详见 [0.8.31 播放与侧栏](PLAYBACK_SIDEBAR_0.8.31.md)。包含 [0.8.30 播放缓冲](PLAYBACK_BUFFER_0.8.30.md) 的首曲有限跳过与连续分段预读；真实账号下的启动耗时和听感仍需现场验收。

0.8.37 统一侧栏管理与 Salt 原生配置页样式：直接复用原生页面布局、背景材质、圆角边框分组和说明文字，跟随宿主主题；列表保留原生标题栏与底部播放器留白。设置入口仍不可隐藏，开关保存失败仍回滚，不改动播放或账号状态。补充明暗主题、窄屏、150% 缩放与短窗口滚动的原生对照渲染回归。

0.8.36 修复 B 站 CDN 跳转导致自动切歌停止：仅允许明确的 HTTPS CDN 域名并校验 TLS、公网地址，跨域不转发账号 Cookie。按 Salt 实际顺序／随机队列完整预缓存后三首（默认 2 GiB 磁盘上限），预取失败最多三次，正式音频创建失败额外重试两次，仍失败自动跳过，连续最多跳过五首；用户暂停、停止、切歌和权限变化取消旧恢复任务。详见 `docs/CDN_PREFETCH_0.8.36.md`。

0.8.35 将侧栏管理收纳成单行入口，设置按钮固定保留；顶部本地歌单恢复 Salt 原生编辑／删除菜单与确认框。新增 Salt 启动首页（歌曲、在线平台、逐个本地歌单、恢复上次）和 Bilibili／网易云默认栏目，移除「打开在线音乐」「记住登录」配置项，登录默认记住。详见 `docs/NAVIGATION_SETTINGS_0.8.35.md`。

0.8.34 修复开启「隐藏切换侧边栏按钮」后顶部快捷按钮行下移的问题：隐藏只压缩宽度，保留原生标题栏按钮高度，快捷行按原生按钮外框定位；补充原生垂直居中布局与 100%／125%／150%／200% 缩放下的对齐回归。

0.8.33 修复侧栏功能与网易云／B 站入口一起消失的问题：改用宿主支持的 Compose 追加钩子处理切换按钮显隐，可选侧栏注册失败不再撤销整个界面接入，修复入口仅重试缺失能力。覆盖三个侧栏开关同时开启的离线渲染回归；升级后请完整退出并重启 Salt。详见 [0.8.33 侧栏恢复](SIDEBAR_RECOVERY_0.8.33.md)。

0.8.32 将合集／作者二级页改为 Salt 原生返回按钮及标题栏，不再叠加平台标题；新增「隐藏切换侧边栏按钮」和「网易云自动换源」开关，均默认关闭。换源按 NeriPlayer 的歌名、歌手、时长和分 P 匹配逻辑寻找 B 站完整音轨，需要已登录 B 站，保留网易云歌单身份、歌词与元数据。登录、风控、网络失败不触发换源，QQ 音乐在 0.8.38 接入并复用匹配策略。详见 [0.8.32 原生标题与换源](NATIVE_SOURCE_0.8.32.md)。

## 无 PowerShell 原生登录（0.8.44）

针对反馈用户的 `NET_WEB/HELPER`，不再只细分错误码：网易云／QQ 官方网页登录、网易云扫码设备环境及账号 DPAPI 保存／恢复均改为直接调用 Windows 接口，不需要 PowerShell。Edge 使用私有临时配置、显式继承句柄白名单和匿名调试管道；启动前挂入 kill-on-close Job，取消／超时只结束本次浏览器进程树。保留 Edge 策略检测，不使用默认浏览器配置、不开放 TCP 调试、不绕过安全策略。DPAPI 沿用旧版 CurrentUser 和 entropy，已验证与旧 .NET 密文双向兼容。详见 `docs/POWERSHELL_HELPER_0.8.44.md`。

## 播放列表切歌封面（0.8.45）

修复持久播放列表补齐封面后缺少刷新、首次图片失败后音频缓存阻止补图的问题。保留安全的公开封面来源，最多两个后台图片请求、每次八秒、最多三次重试；切回旧曲可再次尝试，封面失败不重试音频。按实际 Ready 曲目的 ID 和稳定路径在界面线程重新校验后调用原生封面刷新，防止迟到封面覆盖下一首；封面文件保留到重启，原有队列对象不用替换。QQ 旧专辑地址可回退到同专辑的静态 CDN。详见 `docs/PLAYLIST_COVER_0.8.45.md`；同一最终包包含无 PowerShell 登录修复。

## 网易云扫码安全环境（0.8.46）

参考 NeriPlayer 按官方页面、设备接口、令牌和 Cookie 分阶段等待，避免页面加载前取令牌；一次准备只调用一次 `getToken`。浏览器返回的 `.163.com` 统计 Cookie 不再导致整个设备快照失败，但不会放宽账号 Cookie 域。兼容官方设备标识中的 `%2B`／`%2F`／`%3D`，保留 Cookie 原值，并对二维码 `chainId` 参数进行一次 query 转义，与请求头保持一致。错误保留实际失败阶段，不再全部变成 `NET_DEVICE/DEVICE`。新包包含此前的登录、播放和封面修复。验证范围及参考差异见 `docs/NETEASE_DEVICE_0.8.46.md`。

## Edge 启动兼容（0.8.47）

## 登录认证链路（0.8.48）

对照 NeriPlayer 和 mygo-qyin 检查扫码、OAuth、网页登录和加密恢复。官方网页登录在临时 Edge 仍打开时验证稳定 Cookie；不再先关闭窗口再认证。QQ 必须等待明确登录类型，拒绝同源冲突的 key 别名，正确归一化网页／API 类型；OAuth 使用授权目标匹配的 Cookie 生成 `g_tk`，只发送必要授权 Cookie。网易云沿用实际浏览器 UA 到验证和加密恢复，兼容严格的数字字符串账号 ID。修复账号保存与关闭记住登录的反向加锁。保留官方鉴权要求，不以 Cookie／公开资料代替验证，不自动刷新或绕过风控。详见 `docs/AUTH_FLOW_0.8.48.md`。

## Edge 网页登录启动兼容（0.8.43）

修复缺少 `ProgramFiles(x86)` 等环境变量时，在找到已安装 Edge 前就提前异常退出的问题；补充系统特殊目录和 HKCU／HKLM 的 32／64 位 App Paths 查找，兼容注册在非默认路径的正式版 Edge。冷启动连接由 8 秒延长到有界的 25 秒，仍受整个操作的超时与取消控制。区分找不到浏览器、辅助程序失败、临时目录权限、Edge 启动／提前退出／连接超时和策略限制，不再统一提示验证失败。不绕过浏览器策略，不使用默认配置或读取已有登录。详见 `docs/EDGE_WEB_LOGIN_0.8.43.md`。

## QQ 正式音频播放（0.8.42）

修复 QQ 官方 `UrlGetVkey` 将「song MID + media MID」请求转换为「单 media MID」正式音频路径时，被误判为试听的问题；仅兼容这两种精确身份，继续拒绝试听、其他歌曲、错音质与完整长度不匹配。补充实测返回的确切 CDN `aqqmusic.tc.qq.com`，不扩大到整个 QQ 域。合集播放失败显示脱敏的 QQ 媒体／鉴权／HTTP 阶段与数字码。截图对应 85 首歌单读取成功，前三首修复后均通过正式音频的一字节范围与长度验证，未自动操作宿主队列或触发播放。详见 `docs/QQ_FULL_STREAM_0.8.42.md`。

## QQ 网页登录与封面（0.8.41）

结合 NeriPlayer 的网页 Cookie 收集／资料结构和 mygo-qyin 的歌单封面字段修复：网页登录辅助脚本采用 ACL 隔离的临时文件与短命令启动，避免 Windows 命令行上限；支持 QQ 回调替换窗口、QQ／微信身份别名与类型归一化，不导入分析 Cookie 或一般 QQ 登录密钥。仅在官方鉴权接口验证成功后保存账号，保留脱敏的 `QQ_WEB`／`QQ_VERIFY` 阶段与服务码。增加当前 QQ 封面域名及明确图片缩放参数支持，修复嵌套封面字段回退；QQ 图标按可见矢量边界缩放，与其他入口保持同级尺寸。保留 0.8.40 切歌修复与 QRC 歌词。详见 `docs/QQ_WEB_ARTWORK_0.8.41.md`。

## 切歌卡死修复（0.8.40）

本机现场确认界面线程等待 BASS 混音器锁，持锁线程停在 Windows Media Foundation，两个在线流在读完前已被撤销。自生成 AAC/M4A 在同机 BASS 无声设备中复现旧回调路径卡住。对 MP4/AAC/ASF 输入改为先完整校验并暂存，再交给 Salt 的同一原生解码器；原生句柄释放后清理暂存，不在撤销或切歌时截断其输入。不修改 Salt 安装文件、不更换音频引擎、不全局禁用 Media Foundation；MP3/FLAC/WAV 仍走原有分段流。完整暂存会增加这类歌曲的首播等待和临时磁盘占用，单文件最多 512 MiB、活跃总量最多 1 GiB。已卡住的旧原生调用不能靠热更新解除，需完整重启。详见 [现场与验证边界](DECODER_SWITCH_0.8.40.md)。

## QQ 登录与逐字歌词（0.8.39）

参考 mygo-qyin 优化 QQ 登录：兼容账号资料不返回 UIN、转义 JSONP、可选有效期数字字符串／零值；按真实到期时间截断，有业务拒绝时显示脱敏阶段及服务码。官方网页登录等待 key、ID、登录类型到齐，避免过早关闭窗口。

QQ 歌词优先使用官方加密 QRC，保留原始逐字毫秒、停顿与 offset，转换到 Salt 原生歌词页并配对翻译。损坏／缺失 QRC 自动退回普通歌词，不估算逐字时间。匿名中文／日文真实 QRC 已验证，真实账号确认与播放听感仍需现场验收；详见 [登录优化与逐字歌词](QQMUSIC_LOGIN_QRC_0.8.39.md)。

## QQ 音乐（0.8.38）

沿用 B 站／网易云的原生页面，新增发现、收藏（创建／喜欢）、订阅、搜索、歌单分页／排序／全部播放、原生插播和保存歌单，支持重启恢复与缓存。手机 QQ 扫描官方二维码；也可点击「官方网页登录」使用 QQ／微信手动登录，需 Microsoft Edge。账号使用 DPAPI 保存，不读取其他应用现有账号。

新增 10 档音质偏好、普通歌词与翻译，以及默认关闭的「QQ 音乐自动换源」。只播放官方授权的完整音轨，不播放试听，不绕过会员或风控。真实账号扫码、会员音质与连续发声仍待登录现场验收；详见 [QQ 音乐接入与验证边界](QQMUSIC_0.8.38.md)。

## 主要功能

- 原生侧栏品牌图标、平台发现、个人收藏／订阅、合集数量与作者、头像账号菜单。
- 配置「侧栏设置」控制 10 个原生功能按钮及三个在线平台的显隐，展开侧栏与顶部快捷栏共用；隐藏音乐库不连带隐藏在线平台。「隐藏侧栏」仅在开启侧栏优化时显示，开启后收起侧栏并禁用鼠标悬停自动展开，明确点击切换按钮仍可展开。
- 可选「侧栏优化」默认关闭：开启后收起侧栏，原生导航、Bilibili／网易云／QQ 音乐、新建／导入歌单和本地歌单图标移至顶部切换按钮右侧；再次展开或关闭选项即还原。复用官方图标、按钮和悬停提示，窄窗口支持横向滚动，保留窗口控制与拖动空间。0.8.29 修复启用无效果、后半部按钮被裁切、图标错位和原色丢失的问题，详见 [顶部侧栏布局修复](SIDEBAR_LAYOUT_0.8.29.md)。
- 工具栏与菜单的自绘图标统一细描边，按官方搜索图标的 20 dp 显示尺寸对齐至约 1.25 dp；搜索、排序和按钮容器仍复用官方组件，不缩小点击区域。
- 多页列表在末尾显示上一页、`当前页/总页数`、下一页；按钮文字居中，首页的上一页／末页的下一页置灰且不可点击；单页不显示。上游没有总数时显示 `当前页/?`，不额外全量请求来计数。
- 默认每页最多 30 项，配置「单页上限」可选 20／30／50／60／100／无上限，三平台共用。「无上限」先显示前 30 项，向下滚动时按 30 项追加，不显示上一页／下一页；保留已显示行和滚动位置，失败后可在底部重试。上游内容不足或失效项被过滤时可以少于上限。搜索、排序、全部播放不局限于已滚动加载的项目，原有 10,000 项安全边界不变。详见 [0.8.26 可配置分页](CATALOG_PAGING_0.8.26.md)。
- 合集内搜索和排序覆盖完整列表；支持默认、倒序、标题、作者、时长，B站额外支持播放量排序。完整读取成功且首曲准备成功后才提交替换队列，最多 10,000 项。
- 列表／播放封面保留比例，不裁切或拉伸。固定队列封面路径支持回切、缓存淘汰后的补回；网易云歌词支持 YRC 逐字、普通 LRC 与同时间戳翻译，QQ 音乐支持 QRC 逐字、普通 LRC 与翻译。
- 按 Salt 实际队列完整预缓存接下来 3 首的音频、地址和封面，默认 2 GiB 磁盘上限；当前曲目未缓存部分按读取位置预读两个 512 KiB 分段。切歌／清缓存／权限变化取消旧任务，预取失败有限重试；不启动第二个音频引擎，随机模式不猜测尚未生成的下一轮顺序。
- 分页缓存按平台／账号隔离，每个平台最多 32 页、2 分钟；B站发现整榜短期复用。网易云全量歌单复用已返回详情，缺失详情每批最多 100 首、最多 3 批并发，仍按原始歌单顺序组装。
- 音频分段缓存默认 2 GiB，可选关闭、512 MiB、1/2/4/8 GiB；LRU 淘汰，按有效媒体租约隔离。清缓存不改队列，账号变更撤销旧播放能力。
- 保存到 Salt 歌单的在线歌曲可以直接从歌单播放；保存稳定的平台 ID、标题、作者、时长和本机封面文件，不保存临时音频地址。重启后恢复映射，播放时按当前登录和音质重新解析，支持网易云／QQ 音乐歌词；重复添加不覆盖手动编辑的曲目信息。

本轮菜单与持久化实现、测试边界见 [0.8.22 原生歌单](NATIVE_PLAYLISTS_0.8.22.md)。保存的条目仍需启用插件和联网，平台权限以当前账号为准；本机映射不等于跨设备同步，也不会写入 B站收藏夹或网易云远端歌单。

## 重启后播放恢复

- 双击直接播放、插播和全部播放也使用持久化曲目标识及封面路径，不再仅在「添加到歌单」时保存映射。Salt 恢复原有队列后，插件重新绑定在线解析；不重建队列、不改变随机顺序、不把这些临时队列项自动添加到本地歌曲库。
- 如果启动时早于插件载入导致在线曲目处于未载入状态，点击原生播放时先排入重新载入命令，再执行原播放命令；仅处理本插件拥有的未载入条目，不影响本地歌曲或正在播放／缓冲的流。
- 升级时必须同时移出同 ID 旧安装包和旧解压目录，避免 Salt 继续选择旧版本。旧版本只保存临时 UUID 的在线队列无法反推平台 ID，需要从平台页重新加入一次；新版生成的队列支持后续重启恢复。

原因、恢复条件与验证见 [0.8.23 重启队列恢复](RESTORED_QUEUE_0.8.23.md)。

## 本轮播放流卡死修复

- 对本插件创建的每个播放流单独管理生命周期；地址到期、账户撤销、插件关闭时先关闭对应的读取入口，再释放本地服务。不对 Salt 或其他插件的流执行全局终止，不主动释放宿主持有的音频句柄。
- 修复宿主吞掉读取异常后不断返回 0、再次请求同一失效地址的问题。到达重试上限或持续读取失败后，终止该流并撤销坏地址；以后再次打开同一队列项时重新解析，不反复复用已撤销的缓存。
- 正常 EOF 不视为网络故障，保留解码器尾部探测和向前拖动。网络关闭异步执行，不在 UI 或本地传输线程等待宿主回调锁；不强制自动跳歌、暂停或重建队列。
- 新增真实 Salt HTTP 读取回调、JNA 回调入口、打开途中取消、阻塞读取时关闭、多个流隔离和正常 EOF 回退测试；使用合成音频和模拟原生句柄，不把这类测试当作真实声卡连续播放验收。

定位证据、兼容性边界与升级说明见 [0.8.21 播放流生命周期](STREAM_LIFECYCLE_0.8.21.md)。

## 速度与连续播放

- B站合集优先读取视频详情中完整的合集数据；校验合集身份、总数、唯一视频和首页顺序，通过后不再逐页整理。缺失或不一致时回退原分页，不提交残缺队列；账号／风控拒绝不触发额外分页请求。607 条实测公开合集完整读取约 458 毫秒，仅为目录阶段，不含音频解析和缓冲。
- 修复合集作者只在列表显示、未传给播放队列的问题；真实作者优先，单一作者合集缺失时回填合集作者。只补全旧记录的空作者，保留现有标题、非空作者及稳定 ID。旧空作者队列升级后需重新点一次「全部播放」，再重启即可保留。实现与边界见 [0.8.25 合集快照与作者恢复](SEASON_SNAPSHOT_0.8.25.md)。
- 全部播放的持久化身份改为一次原子批量写入，尚未播放的歌曲不再提前创建空封面文件；重启仍可恢复完整队列。1000 首本机合成数据的保存阶段从约 7 秒降至约 80 毫秒，不代表包含平台网络请求的实际开播总时间。详见 [0.8.24 全部播放加速](BULK_START_0.8.24.md)。
- 同一账号的目录校验／WBI／网易云 CSRF 上下文短期复用 2 分钟，刷新、账号变更或目录请求失败时失效；普通翻页避免重复登录校验和会话预热，不修改二维码安全流程。
- 封面缓存与音频缓存独立：列表缩略图使用会话内 LRU，最多 256 张／48 MiB、30 分钟；退出平台页只取消未完成请求，不再清掉已加载封面。缓存命中直接显示，当前页最多 20 张提前加载、最多 6 张并发，相同图片合并请求；缺失封面补查结果也跨页面复用。B站列表使用等比例 CDN 缩略图，播放页仍读取高清原图。默认 2 GiB 配置仅控制音频磁盘缓存；本轮封面缓存不跨 Salt 重启。不将图片内容写入对话或诊断日志。
- 修复预加载地址只剩十几秒也被复用的问题：开播前按曲目时长检查有效期，不足则重新解析。移除统一 5 分钟的人工截断，仍遵守上游签名期限／`expi` 和本地 30 分钟租约上限。
- 音频分块在完整校验后才交给 Salt；临时连接失败、截断或 5xx 最多重试两次，权限失败、403／429、非法范围和重定向不重试。保留总请求期限、撤销和严格字节范围校验，不自动跳歌或重建播放队列。

实现、模拟断流验证及实际播放验收边界见 [0.8.20 速度与连续播放](PLAYBACK_FLOW_0.8.20.md)。

## 配置与升级

配置保留 11 项：在线音乐入口、记住登录、侧栏优化、B站音质、网易云音质、封面裁切、单页上限、缓存上限、清缓存、修复侧栏、诊断信息。账号管理在平台页完成。

音质是偏好，不是权限承诺：B站 6 档，网易云标准到超清母带共 8 档，实际由官方接口确认。更改音质在下次打开曲目时生效，不主动打断当前歌曲。

账号保存使用当前 Windows 用户的 DPAPI。插件 ID 保持 `io.github.yghfv.saltneri.online`，沿用已有升级识别。旧版本失效条目或重启后遗留的临时在线队列项，请从平台页重新加入；本版直接播放、插播、全部播放和添加到歌单均不再依赖临时队列路径。

Windows 媒体身份修复注册当前用户开始菜单中的 Salt 快捷方式，不改宿主安装文件或用户已有快捷方式。升级后需要完全退出并重启 Salt；注册结果在诊断中查看，系统媒体卡片的实际名称仍需本机验收。

## 本轮界面对齐

- 对齐 Salt 官方桌面标题栏：56 dp 固定高度、24 sp 标题、紧凑边距；滚动列表时标题和账号入口保持可见。
- 「发现／收藏／订阅」收为右上角三个图标，带当前选中背景和官方悬停提示，不再占据整行文字导航。网易云「收藏」对应原来的我的歌单／喜欢。
- 搜索、排序直接调用已安装 Salt 的原生图标；工具按钮复用官方标题栏组件的尺寸、悬停和点击样式。头像缩为 28 dp，点击区域保持 36 dp。
- 平台和合集搜索复用官方胶囊输入框、内置清空按钮、圆形关闭按钮及展开动画，不再使用矩形输入框。输入后按 Enter 提交；内置清空仅清空草稿，右侧关闭或 Esc 清空草稿并收起，不清除已有结果。合集清空输入后按 Enter 可取消筛选。
- 单列封面高度收紧为 48 dp，保留 B站原比例、作者与双行统计对齐；搜索原位展开、不另起一行，窄窗口展开全局搜索时暂时隐藏标题／导航，收起即恢复。

实现与验证见 [0.8.19 官方搜索组件](NATIVE_SEARCH_0.8.19.md) 和 [0.8.18 原生标题栏](NATIVE_TOOLBAR_0.8.18.md)。

## 扫码安全

- 对照 NeriPlayer 补齐官方网页 `createNEFingerprint/getToken` 设备上下文，二维码链路与轮询使用同一设备标识、令牌、Cookie 和 User-Agent，不再发送空令牌或随机 `unknown` 设备标识。
- 设备准备仅在明确扫码登录时运行，可取消；独立临时 Edge 使用匿名管道，不开放调试端口，不读取日常浏览器配置。完成、失败或取消后清理临时环境。
- 设备信息缺失以及网易云 `8821`／`-462` 安全验证响应均停止登录，不自动重试；保留官方网页登录入口，不承诺绕过服务端风控。
- 二维码绑定创建它的客户端和会话；拒绝外来、已消费及关闭后的会话，账号校验仍为登录成功的必要条件。不记录设备令牌、Cookie、二维码内容或上游原始报错。

原因、与参考项目的差异及验证边界见 [0.8.17 网易云扫码安全环境](NETEASE_QR_SECURITY_0.8.17.md)。

## 列表与播放优化

- 网易云歌单兼容创建者缺失、顶层用户 ID、数字字符串、名称换行、空列表与 `playlists` 字段；无效单项不再拖垮整页。分页依据上游原始条目而不是筛选后的数量。
- 列表和播放封面统一使用最高 8 MiB 原图下载上限，列表仍缩小到最长边 480 像素；空封面字段不阻断备用字段。网易云缺失／失效封面可按需读取一次详情补图，不获取播放地址，不阻塞列表。
- B站视频合集的默认／倒序直接使用上游分页顺序，不再为了切换这两项读取完整合集；重复选择当前排序不发请求。
- 标题、作者、时长、播放量等完整排序复用已读页，缺页最多三路并发；期间保留原列表并显示页进度，读取完成后一次应用。完整内容缓存 2 分钟，每个平台最多 2 个合集、合计 10,000 项；刷新和账号变更清除。
- 排序菜单显示当前选择的勾选标记。排序左侧布局图标点击循环切换单列、双列、卡片，按 B站／网易云独立保存，重启后保留；未设置时默认卡片，已有手动选择不覆盖。窄窗口双列自动退为单列，不覆盖保存的偏好。
- B站封面默认保留原比例；配置新增保持比例、居中裁切、靠左裁切、靠右裁切。列表显示即时更新，播放封面在下次打开曲目时更新；不修改源图。卡片缩略图最长边提高至 480 像素，不放大小原图。
- 返回按钮并入标题行，鼠标侧键／播放器返回优先退出当前合集或 UP 主页，内部历史耗尽后才离开插件页面；展开的原生播放页仍优先收起。
- 合集内部隐藏重复合集列，没有可靠归属时不保留空列。表头与数据行共用列宽，作者与右侧时长固定对齐；普通列表右上播放量、右下时长。
- 卡片播放量位于封面左下角、时长位于右下角，使用白字渐变遮罩；标题固定两行、作者一行，避免错位。
- UP 视频主页增加播放量、最新、逆向排序；最新／播放量直接分页，逆向按最早发布优先读取尾页，每页至多三次目录请求，不加载完整主页。中间显示更新时间（接口发布日期）；未知值显示 `--`，不逐条补请求。

歌单与封面验证见 [0.8.16](NETEASE_CATALOG_0.8.16.md)；返回／布局说明见 [0.8.15](CATALOG_NAVIGATION_0.8.15.md)。

## 构建与 CI

版本、名称和插件 ID 来自 [`plugin.properties`](../plugin.properties)。完整构建需要 Python 3、JDK 25、PowerShell 及合法安装的目标 Salt；不分发宿主类或安装文件。

```powershell
./scripts/setup-native-ui.ps1
./scripts/build-local.ps1 -SaltHome 'D:\path\to\Salt Player for Windows' -JdkHome 'C:\path\to\jdk25' -Experimental
```

输出在 `plugin/build/libs/`。构建不替换已安装模组，也不自动播放音频。

不安装 Salt 也能运行公共回归：

```powershell
./scripts/test-offline.ps1 -JdkHome 'C:\path\to\jdk25'
```

推送 main、PR 和手动触发均运行 GitHub Actions 公共检查。**完整自动打包需要先配置带 Salt 的专用 Windows runner**；未配置时打包作业明确跳过，不上传假包。启用步骤、环境变量和下载位置见 [构建与自动化](BUILD.md)。

## 验证边界

- 自动回归使用假上游、真实本机 HTTP 和宿主类／离屏组件，不操作账号，不启动真实音频；通过不等于所有账号、付费内容及实际发声均已验收。
- 队列能力限本次运行和原账号，不跨进程恢复临时链接，也不恢复已退出账号的权限。已打开的超长流暂不在读到一半时更换过期地址。
- 2 GiB 上限只涵盖本插件音频缓存，不包括 Salt 自身流缓冲；封面与歌词另有小额限额。异常终止可能遗留临时文件，不做跨进程广泛删除。
- 无图可补、上游风控、账号权限变化时仍可能失败；使用页面重试或重新登录，不自动循环请求。
- 不读取或回传用户截图、图片内容或 base64 到开发对话；测试图片由本地 fixture 生成。
