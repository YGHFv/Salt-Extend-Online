# 0.8.19 官方搜索组件

## 行为

Bilibili、网易云的全局搜索和合集内搜索均原位展开为 Salt 的胶囊输入框，右侧保留独立圆形关闭按钮。复用宿主主题、边框、占位文字、内置清空图标和淡入／缩放动画，不复制宿主资源，不另起一行。

- 输入框高 36 dp，完整搜索控件宽 184 dp；关闭按钮使用宿主默认控件尺寸（当前测试主题为 32 dp），与其他标题栏按钮垂直居中。
- 展开自动聚焦；输入／粘贴不超过 100 个字符，不接受控制字符。输入本身不发起在线请求，按 Enter / IME 搜索提交。
- 内置清空按钮只清空输入；右侧关闭或 Esc 清空输入并收起，不清除已显示的搜索结果或已提交的合集筛选。
- 合集内允许空输入提交，用于取消筛选；平台全局搜索忽略空输入。
- B站、网易云和合集输入状态互不共用，不注册或覆盖 Salt 本地音乐库的全局搜索快捷键。
- 740／580／420 dp 窗口、1x／1.5x 密度继续保持合集播放、布局和排序按钮可见；窄窗口全局搜索展开时暂时隐藏标题与导航，收起恢复。

## 复用边界

`SaltSearchBindings` 调用已安装宿主的 `ScreenSearchBar` 内部 `TextFieldDecorator`、搜索展开动画，以及相同的 `PillButton` 和关闭图标。输入状态、提交和长度限制由插件控制。

没有整体调用官方 `ScreenSearchBar` 入口：该入口会注册针对本地音乐库的全局快捷键，且不提供在线请求的提交回调和输入限制。复用其实际视觉组件既保持官方外观，又避免全局搜索／合集搜索之间的快捷键冲突或每次输入都请求网络。

宿主签名不可用时，独立回退到插件输入框和带 X 图标的关闭按钮；不锁定宿主版本、不因此禁用整个在线页面。搜索仍需原生 UI 权限，此次没有引入新的账号权限、网络接口或第三方 UI 运行时。

## 验证

- `HeaderSearchRenderTest`：真实 Compose 的官方组件绑定、输入／IME、内置清空、Esc、关闭／重新展开、超长和控制字符拒绝、空提交、结果保留、账号菜单和双击播放（合成队列）。
- `PlaylistRenderTest`：三种窗口宽度与两种密度下的搜索／播放／排序可见性、垂直居中、清空与空提交取消筛选、全部播放保持完整合集语义，以及导航／布局回归。
- `NativeUiContractTest`：故意屏蔽可选搜索绑定后，在线页面与官方工具栏仍可用。
- 使用合成目录、账号、图片和 HTTP 数据；不访问真实账号、不启动真实音频，不改 Salt／Steam 安装目录或已安装插件。

开发工具没有再次读取、编码或上传用户附图，也没有将图片数据写入日志或文档。
