# 0.8.13 项目整理

本轮不改原生 UI 风格，不操作用户账号、不替换已安装模组、不启动音频设备，也不读取用户截图。

## 修复

### 完整合集失败后无法继续分页

「全部播放」进入全量模式时保留普通列表。此前全量读取失败后 `fullMode` 仍为 true、完整内容为 null，翻页被永久拦截。现在失败取消播放意图并返回原分页模式，保留脱敏错误；下一次翻页／刷新恢复普通加载。

若在全量读取期间改为筛选／排序，先清除旧页，避免已经将查询重置为第一页却仍展示第二页的内容。

### 首次封面失败不能恢复

可续期单曲以前仅在首张图片成功时创建封面文件。超时／缺图时原生媒体项得到临时协议路径，之后即使重新解析拿到封面也无处更新。

现在可续期单曲与合集一致：先保留固定、尚未写盘的封面路径。后续正常续期获取到图片时原子填入原路径，不重建队列项。没有新增后台补图重试，也不承诺上游缺图可被修复。

### 缓存隔离与查找

旧 LRU key 使用对象值相等，而范围扫描和撤销使用对象身份，语义不一致。生产租约对象未重写 equals，但将来更换实现有跨租约命中的风险。现在统一按租约身份隔离。

新增每租约的起始偏移有序索引，精确命中仍走 LRU 表；包含区间只搜索同租约、最大块长度内的候选，不扫描其他歌曲。保持重叠区间、相同起点不同长度、LRU 访问更新、删除失败计费和清理语义。插入与配额淘汰不再无条件复制完整 LRU 表。

## 工程整理

- 版本与插件元数据集中到 `plugin.properties`，移除设置标题中的硬编码版本。
- 47 个自动插件测试集中到 JSON 清单，本地／Gradle 共享；扫描源文件防止新增测试漏跑。现场探测不自动执行。
- 加入不依赖 Salt 的核心／网络／缓存回归入口与 main／PR Actions 检查。完整打包在明确启用的专用 Salt runner 上运行，不分发宿主类。
- README 改为当前使用说明，架构、构建、历史记录分离；原 README 完整保留为历史快照，避免早期未实现的方案被误认为当前功能。

## 回归

新增用例先在旧实现上失败，覆盖全量读取失败后的继续分页、初始无图后续期补图，以及值相等但身份不同的租约隔离。缓存额外覆盖重叠区间、包含命中的 LRU 和索引清理。

发布前运行无宿主回归和完整本地构建（含宿主指纹、真实标签读图、离屏 UI、登录 fixture、队列／续期／预加载、包隔离）。通过不等于真实账号或音频设备验收；跨进程队列恢复、已打开流中途换址和系统媒体卡片实际名称仍保留原限制。
