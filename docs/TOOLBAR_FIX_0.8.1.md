# Salt Extend Online 0.8.1

产物：`plugin/build/libs/plugin-io.github.yghfv.saltneri.online-0.8.1-toolbar-fix.spmod`。

## 修正

- 上版将宿主导航行放进 64 dp 宽的标题栏按钮槽；导航行预留图标和内边距后，文字可能没有可用宽度。语义树里有按钮不代表文字实际可见。
- 「全部播放」和「排序」改为专用紧凑按钮，不借用导航行。按文字自然宽度布局，明确设置内边距、最小高度、主题文字色、淡色背景及边框，避免搜索框挤掉按钮文字。
- B站全站搜索、合集内搜索的图标统一只切换输入框展开 / 收起。空输入、已输入、已搜索三种状态下均可再次点击收起，不触发请求。
- 回车执行搜索；收起保留输入文本和已显示的搜索结果。合集内清空关键词后按回车可恢复全部条目。
- 不改变整个合集替换队列、排序、发现、账号或原比例封面的逻辑。

## 验证

- 真实 Compose 离屏测试覆盖 420 / 740 dp 宽度及 100% / 150% 缩放。
- 搜索框收起、展开、搜索后再次收起时，检查两个按钮文本的非零尺寸及文字区域的实际不透明像素，不再只检查语义标签存在。
- 覆盖两种搜索框空输入 / 非空输入 / 已提交后的反复展开收起；确认点击切换不发起额外搜索，保留关键词和结果，回车仍可提交。
- 继续验证排序菜单、完整合集播放意图、页面重建恢复、发现栏目，以及全部已有构建回归。
- 所有测试图片均为本机合成内容，不回传图片或图片编码。未替换正在运行的 Salt 模组，也未调用用户账号播放。

安装后打开任一收藏夹，确认右侧「全部播放」「排序」始终显示；展开搜索、输入关键词、再次点击放大镜应立即收起。需要搜索时按回车。
