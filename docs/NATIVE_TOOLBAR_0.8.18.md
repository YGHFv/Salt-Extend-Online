# 0.8.18 原生标题栏与布局

## 设计

以本机 Salt 1.19.3 歌曲页使用的组件为依据，不重新绘制近似的搜索／排序图标，也不引入第二套 UI 框架。

- 平台标题采用官方桌面标题栏的 24 sp / Medium、56 dp 高度，标题栏不随目录滚动。背景继续透明，由 Salt 绘制原有氛围背景。
- 右上角顺序：发现、收藏、订阅、分隔、搜索、头像。三个目录入口仅显示线条图标，保留中文无障碍标签、官方悬停提示和当前选择背景。网易云收藏仍访问原来的 `MINE` 歌单接口，未改账号或请求语义。
- 搜索／排序图标使用官方组件中的原始内容，全部标题栏工具按钮使用官方 `TitleBarPillButton`。头像显示 28 dp，点击区域与其他按钮一样为 36 dp。
- 全局搜索仍原位展开在搜索按钮前。宽度小于 640 dp 时暂时让出标题和三个导航图标的位置，保证输入框可用；关闭搜索后恢复图标和选中状态，不另起搜索行。
- 列表左右留白为 16 dp；普通封面高 48 dp，B站保持 16:9，网易云方形。标题／作者和播放量／时长共享两行尺寸。卡片继续保留播放量与时长的封面叠加、原比例以及持久化布局设置。
- 合集搜索、全部播放、布局、排序及页尾分页行为不变；点击当前布局不修改数据，不自动播放。

## 宿主复用边界

`SaltToolbarBindings` 通过受检签名连接本机宿主：

- `com.xuncorp.voxzen.ui.component.\u0793`：`TitleBarPillButton`，内含官方 tooltip 与 `TitleBarButton`。
- `com.xuncorp.voxzen.ui.component.\u058f` 的 `\u037f()`：官方搜索图标内容。
- `androidx.compose.ui.\u0a89` 的 `\u0529()`：歌曲页排序图标内容。

只调用已安装宿主的组件，不复制、提取或分发宿主图标资源／实现。签名缺失时退回插件的基本图标按钮，不能因此恢复严格版本锁或禁用整个在线页面。官方按钮内部使用宿主主题和交互反馈，菜单功能仍由插件处理。

## 回归

- `HeaderSearchRenderTest`：真实 Compose 中检查 740／420 px 标题栏图标尺寸与顺序、官方图标调用、头像菜单、窄屏原位搜索展开／收起、IME 搜索及登录取消。
- `PlaylistRenderTest`：740／580／420 dp、1x／1.5x 密度下检查三图标导航、居中与选中状态、官方搜索／排序图标可见、合集操作、作者／统计对齐、卡片与双列布局。
- `NativePageRenderTest`：页尾分页与滚动后标题栏图标仍在顶部、透明背景和单／双击行为。
- 完整本地构建继续执行统一的 51 个插件契约入口及真实宿主 ABI 检查。测试使用合成账号、目录和图片，不访问真实账号或启动音频。

开发工具未再次读取、编码或上传用户附图；附图仅作为当前对话中的视觉参考。未更改 Salt／Steam 安装目录或已安装模组。
