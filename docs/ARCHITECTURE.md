# 架构与生命周期

当前实现入口以 [README](../README.md) 为准。以下是维护约束，不是承诺所有设计项均已实现。

## 模块地图

| 路径 | 职责 | 不应承担 |
| --- | --- | --- |
| `core/` | 曲目身份、歌词选择和发布策略，JDK 17 独立测试 | 宿主反射、网络和凭据 |
| `plugin/.../ExperimentalPlugin.java` | 装配登录、页面、设置、播放运行时及停用清理 | 上游协议细节 |
| `auth/` | 二维码／临时 Edge 登录、账号校验、DPAPI 保存 | 读取用户其他浏览器账号 |
| `library/` | 发现、分页缓存、完整合集、排序筛选、一次性播放意图 | 直接初始化音频设备 |
| `bilibili/`、`netease/`、`qqmusic/` | 官方 API、完整音轨权限、音质选择、歌词 | 会员／风控绕过 |
| `net/` | 有期限可取消请求、固定目标 HTTPS、受限 JSON | 全局 Cookie 或代理污染 |
| `transport/` | 私有 loopback Range 服务、租约、分段磁盘缓存 | 公共媒体代理或离线下载 |
| `host/` | 严格宿主指纹、可逆流 Hook、原生队列、封面、歌词与媒体身份 | 猜测版本、替换安装文件 |
| `ui/` 与 `plugin/src/main/kotlin/` | 原生 Compose 展示、封面加载、用户动作边界 | 自动播放、暴露 URL／Cookie |

## 数据流

```text
侧栏进入 -> NativeDesk -> LibraryController -> CatalogClient -> 官方列表 API
                     <- 平台独立状态 / 不含凭据的行令牌

双击曲目 -> OnlinePlaybackController -> 官方解析 + 完整音轨校验
          -> Salt1193DiagnosticRuntime -> 单曲会话 -> Salt 队列

全部播放 -> 完整合集读取 -> 排序 -> LazyPlaylistSession
          -> 固定曲目身份/封面路径 -> 准备首曲 -> 替换 Salt 队列

Salt 打开队列项 -> 流拦截 -> 有效租约或重新解析
               -> 私有 loopback URL -> 分段缓存 / 固定上游 HTTPS
               -> Salt 自己的音频引擎
```

`Salt1193DiagnosticRuntime` 保留早期类名，现在也是实际在线播放运行时；配置不暴露测试音。不要仅按类名删除它。

## 状态与资源所有权

- `LibraryController` 为 B站、网易云和 QQ 音乐分别保存查询、行令牌、完整内容、排序和页码。离开页面取消未提交播放，不清除已加载列表；账号变更清除对应平台状态。
- `PlatformResolutionController` 使用一名后台 worker 和一个排队任务。新请求取消旧操作，发布前再次核对操作、权限和账号身份，失败信息不含凭据。
- 全部播放只在全量读取完成后提交一次；首曲失败不清空旧队列。完整读取失败时保留的普通分页必须还能翻页。筛选／排序尚未完成时不能把旧页标成新页。
- Runtime 拥有流适配和 loopback 服务。单曲会话／合集会话拥有各自映射、租约、歌词绑定和封面，不撤销其他会话的共享传输。
- MP4/AAC/ASF 在创建解码句柄前完整暂存并核验长度，避免 Media Foundation 在撤销后的短读中占住混音器锁。暂存与分段缓存预算独立；原生 FREE 才释放完整输入，撤销不强行释放宿主句柄。
- 逻辑队列项与短期签名 URL 分离：本次运行中可在过期或淘汰后重新解析，原曲目、账号和 B站 CID 必须一致。两类会话均只保留少量活跃租约／封面，不为全合集下载媒体。
- 封面路径在原生媒体对象创建时确定。实际图片延迟写入、原子替换；淘汰只清除图片，注销才释放路径。不要依赖异步 `updateMediaItems` 及时改变原对象路径。
- 合集预加载只在 Salt 实际打开流后启动，读取原生顺序／随机队列的接下来 3 项；曲目、音质、模式、账号变化使旧计划失效。不预测随机边界重排。
- `RangeDiskCache` 的 LRU 表负责磁盘预算，身份索引只检索同租约可覆盖区间。删除成功才扣除用量；失败不伪造释放。关闭／撤销同步维护两张表。
- `OnlineLyrics` 只为 Salt 正在请求的绑定曲目读取网易云／QQ 音乐原曲歌词，页面加载不预抓歌词。退出账户、会话停用或插件关闭撤销绑定。

## 并发与维护约束

1. 上游 I/O 不应持有页面或单曲会话的全局锁；撤销必须能取消在途请求。流重解析在每曲目锁下合并，不能绕开发布前校验。
2. 页面快照不能包含媒体 URL、Cookie 或二维码文本日志。新增状态字段应是展示数据或短期行令牌。
3. 宿主 ABI 改动先更新指纹和真实类测试，再调整 Hook；不要把编译通过当成二进制兼容。
4. 单曲／全量合集／续期／预加载必须走同一套权限与完整音轨校验，音质偏好不代表权限。
5. 临时文件清理仅操作本次拥有的精确路径，不递归扫描用户目录。崩溃残留不是扩大删除范围的理由。
6. 新增带 `main` 的 `*Test.java` 必须进入 `scripts/contract-tests.json`；自动校验会拒绝漏项。`*Probe.java` 是显式现场探测，永不混入自动回归。

## 后续边界

跨进程队列恢复、已打开流中途换址、Windows 系统媒体卡片真实显示仍是独立工作项。不要因 fake HTTP 或离屏渲染通过就移除这些限制。
