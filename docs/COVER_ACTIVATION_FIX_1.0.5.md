# 1.0.5 封面与启用未生效修复

这是本地 1.0.5 阶段的检查记录，修复随 1.0.6 一起发布。最终版本的启动顺序、100 毫秒权限检查和停止锁处理见 [1.0.6 修复记录](ACTIVATION_LATENCY_FIX_1.0.6.md)。

网易云搜索 `Cerulean World` 时，Anicille 的同名歌曲（3439204130）显示占位封面。公开歌曲详情有合法封面地址，图片返回 HTTP 200、`image/jpg`，原图为 4500×4500、约 1.2 MB。现有解码器限制边长不超过 4096、总像素不超过 1600 万，所以拒绝了这张图。

列表现在请求 `?param=480y480`，播放封面请求 `?param=1024y1024`。仍以原始地址作为缓存身份，缩放请求失败时尝试原图，原图也必须满足原有解码上限。实测该歌曲的两种尺寸均加载成功，列表下载约 30 KB。

## 启用模组后界面没有变化

用户提供的 2026-11-14 诊断文件记录：

```text
Plugin version: 1.0.4
Host version: 1.19.3
STARTUP_READY=true
STOPPED=false
HOST_MATCHED=true
ADAPTER_PRESENT=false
VIDEO_PRESENT=false
UI_PRESENT=false
```

这说明初始化执行到了完成阶段、宿主能力检查通过，但原生界面没有安装。播放适配器本来就是按需启用，`ADAPTER_PRESENT=false` 单独不能说明故障。旧日志未记录权限检查结果和安装异常；宿主日志的 62 行全部被隐私过滤。因此不能从这份日志区分未授权和安装异常，更不能声称已确认某一个异常。

代码存在明确的恢复缺口：后台初始化仅检查一次 `CLASS_TRANSFORM` 权限并尝试一次安装。权限检查暂时返回 false 时直接跳过，安装抛出异常时仅更新内存状态，没有后续自动重试和可见提示。初始化完成与界面生效被当作同一个成功结果。

现在初始化完成后单独启动后台原生功能安装任务。每次重新检查当前实例和宿主权限；授权状态就绪后再安装保存歌曲恢复、媒体身份与原生界面。权限等待最多 60 次，每次间隔 1 秒；安装异常最多重试 3 次，成功后结束。停用／卸载撤销任务，旧实例不能在之后安装。权限未授予时提示在模组管理中授权再重新启用；持续安装失败时提示导出日志。不会自动更改宿主权限。

新日志加入 `CLASS_TRANSFORM_GRANTED`、`NATIVE_ACTIVATION`、`NATIVE_ACTIVATION_FAILURE`、`NATIVE_ACTIVATION_ATTEMPTS`，只输出固定枚举、布尔值和次数，不输出异常正文或账户资料。

安装或重试过程中，设置入口继续使用启动状态提示并立即返回，避免界面点击等待后台安装持有的生命周期锁。成功或重试预算耗尽后才允许正常操作和手动重试；导出诊断日志始终可用。

## 验证

- 封面回归覆盖 4500×4500 原图、列表和播放缩放、原图回退、缓存身份、CDN 忽略缩放时仍执行尺寸限制。
- 使用实际 Java 封面加载器验证反馈歌曲：列表 480×480，播放 1024×1024。
- 启动回归覆盖先未授权后就绪、暂时安装失败后恢复、持续缺类失败上限、取消后的禁止安装与初始化线程不阻塞 AWT。
- 诊断导出回归核对新增状态字段与隐私保护。
- 完整宿主构建通过 102 个合约、137 次宿主／基础模块运行，并通过包隔离校验。最终设置等待门禁补充验证通过 21 项启动检查。

用户现场的授权状态与实际安装异常仍需新版日志确认。更新后完整退出并重启 Salt，使旧模组实例和已加载的界面钩子退出。
