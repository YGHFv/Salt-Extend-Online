# 实验双平台解析、引擎适配与本机测试音

更新：2026-11-07。**这是双平台登录／音频解析预览和本机诊断包，不是已可用的 B站／网易云播放器。**
新增普通方法 Hook 与真实引擎读取接线，提供不依赖账号或平台 CDN 的最小试听入口。
目前完成编译、离线契约和真实Salt HTTP reader测试；最新截图确认本插件账号校验、B站视频列表及音轨准备，尚无队列提交后发声证据。当前0.7.6保留列表封面并移除页面适配/确认控件，双击曲目自动解析/内部接流/一用提交；本轮不自动安装或操作真实播放，BASS发声仍待验收。

## 构建

本地构建需要 Python、JDK 25、固定 Kotlin/Compose compiler 2.4.0 及用户合法取得的原版宿主包。首次执行 `.\scripts\setup-native-ui.ps1` 下载并校验只用于编译的工具，之后本地构建不联网：

```powershell
.\scripts\build-local.ps1 `
  -SaltHome 'D:\SteamLibrary\steamapps\common\Salt Player for Windows' `
  -JdkHome '.\.tools\jdk25\zulu25.38.109-ca-jdk25.0.5.0.3-win_x64' `
  -Experimental
```

不加 `-Experimental` 仍生成被动检查包。脚本不修改 Salt 安装、配置或账号，不自动导入或启用 Mod。
两种模式均先运行全部离线测试，打包后通过 `scripts/validate-artifact.py` 检查主类、权限、按钮、指纹、许可和依赖隔离。

Gradle 对应选项为 `-PexperimentalHostAdapter=true`，如 `:plugin:plugin -PexperimentalHostAdapter=true`。
此 Gradle 路径仍未实际构建验证；本轮验证使用上述本地构建脚本，未关闭 TLS 校验。

## 手动验收

仅在愿意测试时通过 Salt 的 Mod 管理页本地导入实验包；没有自动安装步骤。

1. 先确认本地歌曲、输出设备正常，降低系统音量。导入实验包，明确授权 class-transform。
2. 启用插件并打开配置，查看实验状态中的原生解析/命中/组合计数和登录阶段。此时只安装原生 UI Hook，不安装音频拦截器、不播放；有本插件保存时后台联网校验恢复。左侧音乐库下应出现 Bilibili 和网易云；重新接入后先切到音乐库，再进入平台页。平台页不是“模组管理／无项目”才继续扫码/栏目验收。
3. 点击“启用实验适配（不播放）”。此动作安装普通 Hook、读取真实播放器、写入三个可逆列表并打开回环随机端口；不提交队列。

0.7.6原生页不显示arm/确认按钮：双击曲目就是明确播放操作，后台解析完成后内部接流并提交一次。无需来回点确认，但不自动授予权限。旧配置诊断按钮仍分别arm/prepare/play，不是正常列表播放必经步骤。设置失败提示`ADAPTER_SETUP`，提交失败为`QUEUE_SUBMIT`，返回`SUBMITTED`仍需检查底部播放器和实际声音。
4. 仅当愿意改变当前播放时点击“播放 2 秒本机测试音（会切换当前播放）”。它提交一个明确标为测试音的原生媒体项：44.1 kHz、16-bit 单声道 WAV、440 Hz、约 -26 dBFS 峰值、50 ms 淡入／淡出。
5. 点击“停止实验适配”，核对其他模组／本地歌曲依旧可用。测试项留在队列中，应手动删除；不会自动恢复原歌曲或清空队列。

### 只测试B站解析

无需点击启用适配或本机测试音：填写 BV/av 或 `https://www.bilibili.com/video/BV...?p=2`，选择音轨偏好，
点击“解析/探测B站公开视频（不播放）”，之后点查看实验状态读取结果。
此动作后台访问匿名 API 和选中音轨 CDN 的单字节 Range，不安装 Hook、不打开回环监听、不改变队列。
配置保存、新请求、停止或停用会使旧结果失效；30秒请求期限、权限撤销和租约过期同样失败关闭。
解析器仅保留内存结果，不保存签名URL；解析结果封面仍仅候选。列表封面读取固定公开图片主机的JPEG/PNG，不携带账号Cookie、不落盘。0.7.6播放流程另创建不含音频/凭据的临时封面标签文件供宿主播放栏读取，见[流程说明](FLOW_POLISH_0.7.6.md)。
新增双端明确二维码登录后，B站API解析可使用本插件已验证账号，但不向CDN转发Cookie。
不支持短链、付费/预览内容、ticket／HTML5后备；遇到风控停止。0.6另有独立“准备当前配置音轨”和“确认播放当前已准备音轨”按钮；此解析按钮仍不播放。
协议限制、实网证据和显式 CLI 探测方式见 `BILIBILI_PROGRESS.md`。

### 二维码与安全保存

0.7.6默认记住并自动验证恢复本插件保存；平台页保留扫码/退出，不再显示恢复按钮，配置保留失败后的手动恢复。
0.7 的二维码在 Salt 原生页面内本机生成并展示，不打开浏览器、不使用第三方图像服务、不读取已有浏览器登录。
登录与退出不会自动播放，也不退出其他软件或服务端全局会话。
协议/DPAPI/退出标记见 `LOGIN_PROGRESS.md`；当前原生页面入口和扫码验收以 `NATIVE_UI_PROGRESS.md` 为准。

### 只测试网易云解析

无需启用适配：填写歌曲ID或官方song链接，选择standard/exhigh，明确点击“解析/探测网易云免费完整歌曲（不播放）”，之后查看实验状态。
默认匿名；已登录则重验账号身份，并保留原Cookie作用域。详情GET与EAPI只做读取业务，CDN仅探测1字节，不安装Hook、不修改队列、不下载整曲。
会员/单购/试听、缺失或不匹配的时长/长度、风控和未知字段明确失败；没有自动重试或无验证降级。
本轮237项离线协议、32项共享后台生命周期和真实宿主reader fixture通过，未运行网易云歌曲实网探测；完整限制见 `NETEASE_PROGRESS.md`。

测试不会改播放器音量、EQ 或输出设备；低幅度样本仍可能受用户音效／增益放大，不能把它当成听力安全保证。
显示“已提交测试音”只说明发出了原生队列命令；宿主命令通道可能拒收、解码也可能失败，不等于发声成功。
若没有声音，请记录配置提示、Salt 错误信息、是否出现测试项；不要提供 Cookie 或完整平台签名 URL。

## 真实入口与限制

- `PlaybackController.service` 为 private static final 的 `PlaybackService`。
- `PlaybackService` 的父类实际名为 `androidx.compose.ui.\u0aae`，提供 public final `getPlayer()`，播放器字段为 final。
- 初始播放器是 `com.xuncorp.pisces.\u0528`。`onPlayerSet(PiscesPlayer)` 在服务构造中执行，且发生在父类最终写入 player 字段之前。
- 普通 Hook 只观察所选控制器服务的回调，对其他独立服务或已经失败的原回调不做接管。
- 不 Hook 构造器、native 或 suspend 状态机，不保存／异步传递 `MethodHookParam`。
- 首次连接在 Hook 注册后解析实际服务并 attach；每次显式播放再次解析同一服务、取得播放器、核对覆盖层，避免依赖只有构造时触发的回调。
- `onPlayerSet` 不是所有设备 reset／BASS 资源重建的通知。本版不宣称覆盖所有重建路径；服务身份异常变化或安装失败时关闭适配。
- 停用、撤销权限、回调安装失败会解除本插件资源，其他模组条目／后加包装保留。不会调用全局 `abortActiveStreams(Unspecified)`。
- 权限监视间隔 250 ms；新请求／操作另有即时门禁。已缓冲／缓存的音频可能短暂继续，尚无已验证的“只停止本插件当前原生 handle”机制。
- 原生队列 `addToPlay()` 投递异步播放命令，返回 void。未实现确认宿主接受／开始播放的观察器，不能把入队返回值当完整成功反馈。

## 离线证据

新增 33 项引擎接线检查与 23 项诊断检查：

- 普通方法 Hook 的真实 API／参数类型、无构造时副作用、重复接线、选定服务过滤、原方法失败过滤。
- 权限拒绝、部分安装失败回滚、服务身份改变、权限撤销、旧回调失效。
- 固定 WAV 头、长度、格式、淡入淡出和峰值；不读取任意文件、不让诊断接口接受任意网络目标。
- 真实 Salt HttpRangeSource／nullable Result 代理／回环 Socket 读取同一生成样本、尾部跳读。
- 使用模拟引擎和 recording queue 验证“arm 不入队、play 才入队、close 不清空队列”。
- 传输检查扩展为 123 项，另在 `--limit-modules=java.base` 下重复执行，覆盖诊断 Range 与禁止任意文件参数。

没有构造真实 BASS 音频引擎或安装正式 Hook，所以 private final 写入后的运行时可见性、PF4J 加载、实际发声及设备重建仍需手动验收。
