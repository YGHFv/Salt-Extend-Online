# Salt Extend Online 0.7.9

产物：`plugin/build/libs/plugin-io.github.yghfv.saltneri.online-0.7.9-search-account.spmod`。

## 列表分页

- 分页是滚动列表的最后一项，位于所有可见条目之后，不再固定在播放栏上方。
- 按钮中间显示 `当前页/总页数`；第一页禁用上一页，最后一页禁用下一页，只有一页时整行隐藏。
- 优先读取上游总数或搜索总页数，不使用过滤后的可见行数推断分页。整页条目失效也能继续翻页。
- 上游只提供 `more` 而没有总数时显示 `当前页/?`；读取末页后记住总页数，返回前页时保留。打开其他列表或搜索新关键词时重置。
- 缺少分页标记时沿用最多补查一页的策略，不为了显示数字遍历完整账号列表。最大页数仍为 500。
- 翻页回到顶部，列表底部保留宿主播放栏安全间距。

## 标题栏与账户

- 平台标题右侧显示已验证账号的头像；头像取自官方账号校验结果，不使用浏览器登录态。
- 点击头像打开昵称、切换账户、退出登录菜单。菜单使用 Salt 主题色，跟随窗口缩放。
- 切换账户先撤销当前插件账号及其保存凭据，再显示新账号的官方扫码二维码。当前仍只保存每个平台一个账号，不是多账号选择器。
- 退出登录后头像恢复为登录图标；点击图标重新扫码。登录中的二维码、取消操作和必要错误提示保留。
- 头像缓存独立于列表封面缓存，不占用 20 个列表封面位置；换账号后不复用旧头像。图片请求不带账号 Cookie，不落盘。
- 头像采用圆形裁切；列表与传给宿主的播放封面仍保留原比例。

## Bilibili 搜索

- 头像左侧的搜索按钮展开 / 收起原生输入框。仅输入不会发送请求；按回车或点击搜索后提交。
- 使用官方 WBI 签名视频搜索接口，每页 20 项，读取上游总页数；翻页保留关键词。
- 当前搜索要求本插件已验证的 B站账号。未登录、网络失败和平台拒绝均显示错误，不尝试绕过验证。
- 搜索范围是 B站视频，不包含用户、专栏或直播。过滤无效视频 ID、无有效时长和重复条目；清除标题中的搜索高亮标签。
- 单击选中、双击解析并播放，与收藏 / 合集曲目共用播放入口；不是仅打开网页。
- 输入最长 100 个字符，不接受控制字符；请求参数编码与签名处理由统一 WBI 实现负责。
- 关键词只用于当前界面和官方搜索请求，查询对象的诊断字符串不含关键词；账号 Cookie 仍限定在平台 API 域名。

## 回归与边界

本地构建使用 JDK 25 和 Steam Salt 1.19.3 的实际 classpath，执行宿主 ABI、账号、目录、原生界面、封面、队列与流传输测试。

- 离屏原生 Compose 测试覆盖 420 / 740 宽度、0 / 2 / 20 / 21 项列表、滚到末尾才出现的分页、页码位置和鼠标前后翻页。
- 真实 Compose 语义及鼠标测试覆盖头像菜单、切换账号、退出、搜索框输入、提交前不请求、IME 搜索与结果双击入队。
- 假 HTTP 覆盖搜索签名、中文和特殊字符编码、高亮标题、时长、失效结果过滤、页码校验、未登录和平台错误；工作流覆盖关键词翻页及旧结果失效。
- 登录协议测试覆盖官方头像 / 昵称解析、账号恢复后的新 revision，以及退出后清空资料；已有封面安全和账号隔离回归保留。

测试使用合成账号、合成图片和录制队列，不回传截图或图片编码。不读取真实账号、不替换已安装模组、不启动真实音频设备；真实账号搜索、扫码切换及发声仍需安装后验收。

本次未配置自托管 GitHub Actions runner。完整打包依赖本机专有 Salt 宿主包；没有将该包或用户凭据提交到 GitHub。

## 安装后确认

1. 在 Salt 模组管理导入新版，同 ID 旧版不要同时启用。
2. 打开超过 20 项的收藏 / 合集，滚到列表最后，确认分页与 `x/x`；单页不显示分页。
3. 登录后确认标题行右侧头像，点击检查菜单；切换账户后使用另一个账号扫码，检查头像与列表更新。
4. 点击头像左侧搜索，输入视频关键词，按回车或点击搜索；双击一个可用视频确认播放。
5. 退出后确认头像变为登录入口，旧账号列表 / 待提交播放结果不能继续使用。
