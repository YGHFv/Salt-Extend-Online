# Salt Extend Online 0.7.7

更新：2026-11-07。产物：`plugin/build/libs/plugin-io.github.yghfv.saltneri.online-0.7.7-online-polish.spmod`。

## 修正内容

### 高清播放封面

此前播放元数据直接复用了列表加载器的 96×96 PNG，大图播放页放大后明显模糊。
现在列表仍使用轻量缩略图，播放则单独移除已知 CDN 缩略处理，按原图读取并中心裁切，
最高保留 1024×1024；原图小于此尺寸时不放大。解析后仍由 Salt 的标签读图和原生播放页展示。

- 列表下载上限仍为 1 MiB；单张播放原图上限为 8 MiB，独立 3 秒请求期限。
- 解码前限制单边 4096、总像素 1600 万；归一化 PNG 和临时 FLAC artwork 元数据上限为 5 MiB。
- 不发送账号 Cookie / Authorization，不跟随重定向，只访问既有白名单图片域名。
- 原图失败仍降级为无封面，不阻止音轨播放。临时标签文件继续随播放会话回收。
- 旧曲目的播放封面不会原地替换；安装新版后需重新双击曲目。

### B站收藏合集

此前 `collected/list` 中的 `type=21` 条目被无条件禁用。
现在将普通收藏夹和视频合集分别建模，合集保留 season ID 和作者 MID，
通过 WBI 签名的 `seasons_archives_list` 每次读取最多 20 个视频，禁止一次拉取全部页面。
优先使用 `season_id` 而不是收藏条目的外层 `id`；翻页时保留合集身份，验证返回作者和 season ID。
打开合集只浏览，双击视频才进入现有解析、接流、提交和 play 路径；默认播放 P1。
无效、删除、缺少作者身份或平台拒绝访问的内容不伪装成可播放资源。

### 页面与名称

- 空列表、少于 20 项和恰好 20 项的单页列表不渲染分页控件。
- 是否还有下一页以 API 的总数 / `has_more` / `more` 为准，不能用过滤后的可见行数猜测。
- 最后一页保留上一页入口，边界方向禁用；已有分页守卫继续拒绝越界操作。
- 侧栏使用 Simple Icons 16.36.0 的 Bilibili / NetEase Cloud Music 矢量路径，随包内置，无图标网络请求。
- mod 名称为 `Salt Extend Online`，插件 ID 保留 `io.github.yghfv.saltneri.online`，避免破坏原有账号和配置。

## 手动验收

1. 在模组管理导入新版，避免同时启用同 ID 旧包。
2. 打开 B站「收藏 / 订阅」，单击有效合集并双击视频，确认开始播放；多页合集可前后翻页。
3. 打开播放页，确认封面比旧版清晰。平台原图本身低清时无法补出细节。
4. 查看单页收藏夹无分页栏、多页最后一页仍能返回；侧栏显示两端品牌图标。

歌词、整单自动连播、搜索和取流租约续期仍不在本次实现范围内。
