# QQ 登录优化与逐字歌词（0.8.39）

参考 mygo-qyin 固定快照 `152d32d2a0ba49a3074b120030684a2d22d899cf`。
继续使用现有 Salt 原生平台页、账号生命周期与歌词扩展，不引入第二套播放器。

## 登录优化

- `GetLoginUserInfo` 成功返回的 `info` 用于验证音乐凭据；该接口通常不返回 UIN，
  账号 ID 沿用 QQLogin 响应，不再额外依赖公开主页接口。若返回 ID，则必须一致。
- 头像支持 `avatarUrl` 等字段；资料缺失可沿用已验证会话资料或显示账号 ID。
- QQ JSONP 仅按数据解析，支持 `\x26`、`\u0026`、转义引号等，不执行脚本；
  严格限定 callback、字段数量和响应大小。
- `keyExpiresIn`、`musickeyCreateTime` 接受数字或数字字符串；零值及不可用的
  可选元数据不误判为登录失败。有明确创建时间和有效期时，按真实到期时间截断。
- QQLogin 必须是正确凭据类型、成功业务码及有效账号 ID；错误保留固定阶段和
  公开数字代码，不显示 Cookie、code、签名地址或原始响应。
- 新二维码准备失败不保留旧图片；确认前再次检查实例身份、取消和到期状态。
  OAuth 临时 Cookie 仍按域隔离，不受同名父域删除 Cookie 干扰。
- 官方网页登录等待音乐 key、账号 ID 和登录类型全部到齐后再关闭临时 Edge，
  QQ／微信按凭据类型选择 ID，避免首个 Cookie 到达就过早结束。

## QQ 逐字歌词

- 首先请求官方 `GetPlayLyricInfo` 的 `qrc=1`、`crypt=1`。
- 使用 QQ modified DES-EDE、32 位字节序与 zlib 解码。解压验证完整校验和，
  限制输入／输出为 256 KiB 级，支持取消，不使用普通 DES 错误解密或截断容忍。
- 解析 QRC XML `LyricContent` 或裸文本，保留每个字的绝对毫秒开始、持续时间、
  空格、标点、真实停顿和 offset；转成 Salt 原生 Enhanced LRC。
- 翻译可解密 LRC／QRC；按最接近的原文行匹配（小于 1500 ms），输出同时间戳
  翻译行。坏翻译不丢弃原文字轴。
- 缺失／损坏 QRC 时依次使用普通歌词请求及旧官方歌词端点，不估算逐字时间；
  登录拒绝不匿名重试，退出／换账号会撤销旧歌词请求和缓存。
- Salt 当前解析器忽略空的尾时间标记：其可见行结束时间是最后一个实际字结束，
  不伪造延长字来填满 QRC 的尾部静默。
- 保存到本地歌单、重启恢复和自动换源继续按原 QQ song MID 获取歌词。
