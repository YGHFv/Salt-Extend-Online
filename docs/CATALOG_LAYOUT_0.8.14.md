# 0.8.14 列表、排序与作者页

## 排序不再清空页面

- B站视频合集的默认／倒序通过 `seasons_archives_list` 的 `sort_reverse` 参数在服务端分页完成；606 条合集切倒序不再必须等待 31 页全量下载。普通收藏夹没有同样的倒序参数，仍走完整排序。
- 标题／作者／时长／播放量等需要完整元数据的排序，不把当前 20 条当作整个合集。复用已读分页后，缺失页最多三路并发读取、按页码合并、去重；只在全量成功后应用。
- 只验证一次账号，每个并发 worker 使用独立的已验证 Cookie jar；不使用用户浏览器 Cookie、不缓存播放授权。
- 无总页数时保留逐页终止协议。读到不同总数时拒绝混合提交，提示刷新；上游报错不自动无限重试、不提交部分队列。
- 全量加载期间保留现有行和封面，显示页进度，避免空白“卡住”；未完成时不把旧页显示成新页。单页内容本地排序、重复选择同一排序不请求。
- 已完成合集缓存 2 分钟，每个平台最多 2 个、总计 10,000 项，账号／刷新／权限变更清除。全部播放仍覆盖完整合集并遵循界面选定排序及 Salt 的顺序／随机模式。

## 原生布局与封面

标题操作依次为搜索、播放、切换列表、排序。排序菜单在选中项前显示勾选，保留各项图标；布局菜单提供单列、双列、卡片，窗口不足 600 dp 时双列退为单列，卡片随宽度显示 1–6 列。

单列沿用 Salt 歌曲行的结构：标题下是作者，中间为当前合集，右侧为时长。双列压缩次要信息，卡片显示封面、标题、作者、合集／时长。切换布局不访问目录 API，不重新提交播放，页面返回保留所选布局。

B站默认使用横向封面区域并保持原图比例；网易云使用方形区域但不默认裁切。图片不拉伸、不放大小原图，列表／卡片缩略图最长边上限 480。配置 `cover.mode` 提供：

| 值 | 行为 |
| --- | --- |
| `fit`（默认） | 保持完整图片比例 |
| `center` | 方形居中裁切 |
| `left` | 方形裁切优先左侧，纵向居中 |
| `right` | 方形裁切优先右侧，纵向居中 |

列表／卡片只改变绘制方式，播放封面处理的是内存副本并写入本次临时封面文件，源图片不变。更改设置不打断当前音频，播放封面在下次打开曲目时生效。

## 作者主页

只将 API 明确给出 UP 主 ID 的作者显示为链接；没有身份数据时不根据姓名猜测账号。

点击后在插件内显示作者标题和“视频 / 合集”页签：视频使用签名接口 `/x/space/wbi/arc/search`，合集使用 `/x/polymer/web-space/seasons_series_list`。视频双击沿用原播放链路，合集单击打开原合集详情。返回按钮恢复原查询、排序和筛选，最多保存 16 层导航位置，账号变更全部撤销。

协议字段参考 NeriPlayer `fd7fdb757821fda7a62aee3a2b7cecf3a4b8bfe0` 的 `modules/platform/.../BiliClient.kt`：`getUploaderVideos`、`getUploaderContents`、合集 `sortReverse`。仅只读能力，不移植点赞、关注等写操作。

## 明确边界

- 第一次标题／作者／时长／播放量排序仍需要缺失元数据，网络慢时会显示进度，不承诺瞬时排序。默认／倒序快速路径只用于 B站视频合集，且未处于本地筛选模式时生效。
- 作者主页当前支持 B站；不是网易云歌手页。合集页只显示可按现有链路播放的 season 合集，series 类型不伪装成 season。上游分页总数可能包含未展示的 series。
- 合集列显示正在浏览的合集／收藏夹；搜索和发现未返回可靠归属时留空，不为每行额外查询或猜测。未知时长显示 `--:--`。
- 作者空间接口仍受官方登录／风控／可见性约束。自动测试不代表所有真实账号均可访问。
