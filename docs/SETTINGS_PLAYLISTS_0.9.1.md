# 0.9.1 配置整理与平台歌单操作

配置主页面将侧栏管理、自动换源、音质、默认栏目分别保留为一个入口。
侧栏管理包含全部入口显隐、侧栏优化、隐藏侧栏、隐藏切换按钮和修复侧栏入口。
默认栏目包含 Salt 启动首页、动态本地歌单以及各平台栏目。
二级页沿用原来的 `config.json` 和配置键，升级保留已有选择；保存失败回滚，
修改音质或换源选项后撤销旧的待播放结果。

网易云、QQ 音乐、酷狗音乐、Apple Music 各有独立自动换源开关，默认关闭。
Bilibili 是备用音源，无自动换源开关。完整音轨不可用时，通过原歌曲标题、
作者、时长匹配 B 站视频分 P；保留原平台歌曲 ID、标题、专辑、封面及歌词身份。
原账号或 B 站账号退出、替换时，已准备的备用音轨随之撤销。
登录失败、网络异常和身份校验失败不会触发换源。

歌曲右键菜单新增“收藏”子菜单，读取当前平台账号可写歌单。
已包含该歌曲的歌单显示“已收藏”并置灰，未完成成员检查的歌单暂不可点击。
成员读取并发上限为三，结果按账号缓存两分钟；写入前重新检查歌单权限和成员，
成功后清除平台歌单缓存。网易云成员读取使用 `trackIds`，避免为置灰判断加载
整单歌曲详情。平台歌曲收藏与原有“添加到歌单”的 Salt 本地歌单功能并存。

歌单右键菜单新增“播放全部”和“订阅歌单”。播放全部加载完整歌单，
沿用现有 Salt 队列提交路径。订阅将歌单收藏到当前平台，自己的或已订阅的
歌单不可重复订阅。Apple Music 当前展示的资料库歌单已经在资料库中，
订阅项保持置灰；收藏歌曲只列出 API 标记 `canEdit` 的资料库歌单。
只有 Bilibili 曲目卡片左下角显示播放量，其余平台保留右下角时长。
全部界面名称统一使用“酷狗音乐”。

接口映射参考现有 NeriPlayer、kgka Music、MusicOne，以及 QQMusicApi
的 `PlaylistDetailWrite.AddSonglist` / `PlaylistFavWrite.FavPlaylist`
请求和 Apple Music API 的资料库歌单曲目接口；使用插件已有的受限 HTTPS
传输，各平台凭据只传给对应 API。没有自动创建或修改用户歌单的后台任务。

回归包含原生 Compose 设置页与菜单交互、明暗主题、缩放和滚动，
以及五个平台 HTTP 模拟响应下的权限、成员、重复操作、服务端拒绝、
CSRF、凭据隔离、缓存与账号撤销。模拟响应验证不能替代真实平台写入验收。
实际订阅账号的 Apple Music DRM 歌曲播放仍待验收，延续 0.9.0 的限制。

播放断续排查发现，CDN 的实际播放读取与预加载共用整首歌的锁，
慢速预加载会阻塞其他分段。现在仅协调相同分段，超过 200 毫秒仍未完成
的相同分段允许实际播放独立获取；无关配置保存不再清空读取窗口。
慢速模拟上游保持阻塞期间，实际播放请求可以独立完成。

Apple Music 原先每读取一个分段都会暂停 MusicKit，再读取时重新启动，
实时解码无法提前积累音频。现在首次读取和拖动进度时预缓冲约四秒，
随后持续产生 PCM；浏览器队列到达 1 MiB 时暂停，低于 512 KiB 时恢复，
解密音频仍仅保存在有限内存中。真实 Edge 的合成音频验证包含缓冲、
流量控制、Salt 原生 BASS 解码及拖动定位。原生 WAV 打开时还会探测文件尾部，
现在在交出原生句柄前重新预热开头的后续分段，避免尾部探测打断连续生产。
按实际播放速度连续读取 11 秒跨越四个分段，通过回归；准备失败或被撤销时
释放尚未交给 Salt 的原生句柄。该验证不代表真实 DRM 曲目验收。
