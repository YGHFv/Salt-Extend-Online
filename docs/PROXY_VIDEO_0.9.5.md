# 0.9.5 逐源代理与整页视频

模组配置新增「代理设置」，进入二级页面后可分别设置 Bilibili、网易云、
QQ 音乐、酷狗音乐和 Apple Music。每个源默认「直连（绕过代理）」；
选择「使用系统代理」后，新请求使用 JVM 提供的系统代理选择器，
Windows 上同时支持当前用户已开启的手动 HTTP／SOCKS 代理。
设置沿用插件 config.json，切换立即保存，重启后保留。

接口、登录验证、封面、音频和视频共用插件网络连接层。
HTTP 代理通过 CONNECT，SOCKS 通过 SOCKS5 连接已验证的上游地址，
TLS 继续验证原始域名。直连请求不读取系统代理，回环播放通道保持本地。
选择代理但没有配置可用代理时，请求失败；请先在系统中设置代理。
当前支持无需代理认证的 HTTP／SOCKS5，插件连接层不解析 PAC 脚本。
插件启动的 Edge 登录环境和 Apple Music MusicKit 播放环境同样遵循
对应源的直连／系统代理设置，已打开的环境在下次创建时使用新设置。

视频画布覆盖整个播放页，保持原始画面比例；比例不同的窗口使用黑色留边。
顶部原生标题按钮、视频切换按钮和底部原生播放条叠加在视频上。
视频加载完毕后，指针静止 3 秒自动隐藏控件；移动、点击或滚轮恢复显示。
原本的底部播放条在视频模式中由新的位置接管，避免重复快捷键和交互。
视频继续静音，暂停、进度和播放速度跟随 Salt 的音频队列。

视频模式跟随切歌：下一首 Bilibili 视频或网易云／QQ MV 自动加载。
MV 详情异步发现期间保留视频加载状态；没有视频则显示普通播放页，
随后遇到带视频的歌曲仍可自动恢复。点击返回封面和歌词或取消加载后，
后续歌曲不会自动进入视频；切换账号、视频失败和关闭模组也会退出模式。
过期的请求不能替换新歌曲画面。

回归覆盖每源默认直连、独立切换、域名归属、HTTP CONNECT／SOCKS5
本机握手、代理拒绝、原生代理二级页面和保存行为；视频使用本机合成流
验证切歌续播、MV 发现、无视频歌曲、加载取消，以及 Direct3D 实际窗口
中的控件隐藏与指针恢复。真实平台可用性仍取决于账号和网络环境。
