# Salt Extend Online 0.7.8

产物：`plugin/build/libs/plugin-io.github.yghfv.saltneri.online-0.7.8-catalog-artwork.spmod`。

## 页面修正

- 不再显示正常播放提交的 `[SUBMITTED]` 说明、列表已读取、DPAPI 保存信息和开发功能说明等灰字。
- 错误状态单独传递给页面，解析失败、提交失败和扫码提示仍显示，避免操作失败却没有反馈。
- 分页移出滚动列表，固定在 Salt 底部播放栏上方；普通窗口中无需滚到底即可上一页 / 下一页。
- 分页读取布尔值和数字形式的 `has_more` / `more`、总数以及合集 `meta.total`；缺少分页信息且当前原始页满 20 项时，最多补查一页，不抓取全部列表。
- 列表模型保留上游分页信息，展示与行操作只发布可用条目。过滤已失效项不会把多页误判为单页；整页失效也可继续翻页。
- 切换列表或翻页后滚动位置回到顶部。

## 原比例封面

- 列表图片最长边 168 像素、播放图片最长边 1024 像素，保持源图比例，不做方形裁切，也不放大小图。
- 列表使用 84×56 dp 图片位置，按比例完整显示；传给宿主的临时 FLAC 标签记录真实宽高，播放页如何显示由 Salt 决定。
- 图片地址统一移除 B站 CDN 裁切 / 格式后缀和网易云已知尺寸参数，补充明确的 B站图片域名白名单及 `pic` / `cover_url` 字段。
- PNG / JPEG 使用 ImageIO；WebP 使用宿主已有 Skia 解码。解码前校验尺寸，不安装或打包新解码器。
- 订阅合集缺少图片地址时，仅为当前可见条目读取一次签名合集元数据（`page_size=1`），优先合集封面，缺失时取首个视频封面。
- 已提供的合集图片加载失败时，允许一次元数据替代地址查询；不对同一地址自动循环重试，不请求音轨。
- 列表图片下载上限 4 MiB，播放原图 8 MiB；单边最高 4096、总像素最高 1600 万。缓存最多 20 项、单图片 worker，最终播放 PNG 上限 5 MiB。
- 图片 HTTP 不带账号 Cookie / Authorization、不跟随重定向。元数据 API 使用本插件已验证账号，换页 / 换账号 / 停用后撤销旧结果。

## 验证边界

完整本地构建使用 JDK 25 和 Steam Salt 1.19.3 原始 classpath，运行协议、账号隔离、封面、原生页面和播放相关回归。

新增覆盖：

- 420 / 740 宽度、768 高度下，0、2、20、21 项分页是否可见，以及真实鼠标点击前后翻页。
- 全页条目失效时仍能点击翻页；单页不显示分页。
- 灰字不在页面语义树中，错误信息继续通过独立字段发布。
- 横图、竖图、小图完整保留比例；真实 Salt 标签读取验证 1024×576 图片不被改成方形。
- WebP 真实解码、CDN 参数规范化、缺图元数据与首图回退、图片失败替代地址、缓存不重复请求、导航失效拒绝迟到封面。
- API 总数缺失时的有界下一页探测，以及已知恰好 20 项时不多发请求。

所有图片均为合成测试内容，测试只输出结果，不回传截图或图片编码。API 和队列测试使用 fixture；未使用用户账号、未替换已安装模组，也未运行真实平台音频。

## 安装后确认

1. 通过 Salt 模组管理导入新版，同 ID 旧版不要同时启用。
2. 打开超过一页的收藏 / 合集，在普通窗口直接点击底部分页按钮，确认前后翻页。
3. 确认失效条目和调试灰字不再出现；原先缺图的有效合集可等待按需补图。
4. 重新双击歌曲，刷新原比例播放封面。上游无图或网络拒绝时仍显示占位，不伪造封面。
