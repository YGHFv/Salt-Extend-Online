# 1.0.7 启动未知错误与长视频加载

## 启动恢复

现场只读检查发现播放器保留了 `BassPiscesPlayer.processPrepare` 的异常，被宿主转换为 `Unknown error`。恢复队列选中的曲目是本插件 `saltneri:saved:<hash>`，对应 `saved-online-tracks/<hash>.flac`。该文件是保存封面和曲目信息的 FLAC 容器，没有可播放音频帧。宿主启动恢复协程在选择曲目后立即提交 Prepare，此时在线播放适配器尚未完成绑定，可能把容器作为本地音频解码。之后手动播放重新解析在线音源，因此错误弹出后仍能使用。

针对 Salt 1.19.3，在插件启动且已授权时先注册两个有限钩子。启动恢复只保留宿主原来的 Select；仅在该恢复协程的同步调用范围内，抑制同一个播放器的 Prepare。严格匹配插件保存 ID 和规范化后的保存路径，不影响其他本地文件、手动播放或切歌。后续 Play 继续使用已有在线恢复流程，先绑定适配器再 Prepare/Play。权限撤销和卸载使钩子失效并清理调用范围。

不能直接跳过整个恢复协程：Salt 当前普通方法 Advice 会丢弃替代的引用返回值，导致应返回的 boxed `ChannelResult` 变为 null。本次保留原恢复 body，只在 Prepare 的未装箱结果处返回成功。注册不读取保存库、不请求网络、不操作音频设备，也不等待 AWT。

`SavedStartupPreparationTest` 使用真实宿主恢复协程的 class bytes、Salt 的 ByteBuddy/Advice 转换器和隔离播放器夹具，复现旧 Prepare 错误并验证修复后的 Select、boxed 返回值、手动 Prepare、路径边界、权限撤销、异常退出和卸载。现场检查没有重启或改写用户运行中的 Salt；真实用户冷启动弹窗消失仍需更新后重启验收。

## 视频加载

开启缓存时，旧 Range 服务把每次初始请求对齐并扩大到完整 2 MiB。播放器即使只探测几十字节的 MP4 文件头或尾部索引，也必须等待整个块下载完，才能收到响应。长视频的首部、尾部和跳转会重复出现这种等待。

冷读取现在尊重实际 Range：首个前台分块最多 512 KiB，文件头与尾部的短请求只下载需要的字节；后续连续读取仍使用最多 2 MiB 分块，在对齐边界重新接入有限预读。已有完整缓存块仍能直接满足小请求。保留完整 Range 响应校验、短读重试、授权撤销、下载去重及前台不等待慢预读的机制。

后台原来依次执行“当前视频首尾 → 当前视频完整下载 → 下一首”，默认预算内的长视频会占用工作线程和带宽。现在每首只预热有限首尾，随后处理后三首；每首请求总时限从五分钟缩短为十五秒。播放中的连续缓冲由实际读取推动，预热不会串成完整下载。视频关闭、队列、清晰度、账号和缓存变化继续取消旧计划。

参考 [PiliPlus](https://github.com/bggRGjQaUbCoE/PiliPlus/tree/217fb54f51f6764176319bbdedab2a7522d75401) 的 `lib/utils/video_utils.dart`：普通 upos 镜像优先于 `os=mcdn`、302 镜像和 MCDN 地址，包括编码后的查询参数；只排序服务端返回的完整 URL，保留原签名和转义，不替换主机。清晰度、编码选择、账号拒绝和官方备用地址的原有规则保留。检查了 PiliPlus 的有限 mpv 缓冲设置，Salt 现有 32 MiB／20 秒缓冲继续使用；此次可复现的等待发生在传输分块和整段预下载。

`VideoLoadingContractTest` 使用 1 GiB 的虚拟文件、受控慢 CDN 和真实本地 HTTP Socket，覆盖短头、后缀尾部、跨块跳转、缓存命中、关闭/清理/撤销，以及当前加后三首的公平预热。它不分配或下载完整大文件。受控边缘每 64 KiB 延迟 20 毫秒，在相同夹具中对比基线 1.0.6 与修复版：首次响应从 719 毫秒／2 MiB 降为 218 毫秒／512 KiB。这个结果只用于对比传输自身的等待，不能当作真实网络提速承诺。

## 验证

定向验证通过：启动准备 18 项、既有保存播放恢复 14 项、后台启动 28 项；视频加载 36 项、传输 215 项、Bilibili 188 项，以及当前加后三首缓存合约。

全新完整构建通过 104 个合约、140 次宿主／基础模块运行及安装包隔离校验，产物为 `plugin-io.github.yghfv.saltneri.online-1.0.7.spmod`。默认回归不打开前台终端、视频测试窗口或控制鼠标。历史卡死回归继续覆盖权限/启动/停止的等待链、AWT 取消、缓存维护、视频句柄/画面异步退役、Compose 卸载和原生窗口回调存活；需要前台窗口及真实鼠标的部分明确跳过。

更新后完整退出并重启 Salt，以加载 1.0.7。构建辅助任务只按需执行一次并退出，不注册开机或登录自启。
